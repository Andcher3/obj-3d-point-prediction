方向一方法设想 | Smartphone IMU Activity Forecasting

基于 Future Patch Label Sequence 的动作延续与切换预测

核心思想：不把每种动作切换都做成独立 transition 类别，而是预测当前与未来 patch 的标签序列，再由序列变化和分类置信度推导延续概率、切换时机和下一动作。

当前定位：周三组会可汇报的研究方案草案。已完成相关论文范式梳理、模型结构选择、训练策略设计与可视化材料准备；尚未宣称完成实验。

1. 问题重述

输入手机 IMU：acc x/y/z + gyro x/y/z 连续序列。

输出当前动作、未来动作序列、延续概率、切换时机、下一动作。

关键转变从单窗口 HAR 分类，转向连续流上的 label sequence forecasting。

past IMU patches -> p(y_t), p(y_{t+1}), ..., p(y_{t+H})

2. 为什么不主用 transition class

  • `<sit-2-stand>` 有直觉价值，但作为主标签会带来类别膨胀和样本稀疏。
  • 较新的相近任务更常预测未来标签序列或未来动作段，而非枚举所有 A-to-B 切换。
  • 未来序列中第一次 label 变化即可给出切换时机；变化后的 label 即下一动作。
current: sit future: sit, sit, stand, stand => switch at first stand => next action = stand

保留空间transition type 可作为后续辅助头或分析标签，不作为第一版主任务。

3. 相关范式依据

P2LHAP

sensor patches -> patch-level activity label sequence；forecast 直接输出未来活动标签。

FUTR

learnable action queries 并行预测未来动作与 duration，避免自回归错误累积。

ActFusion

把未来不可见部分视作 mask tokens，通过补全动作序列完成 anticipation。

本方法

采用 parallel query decoder 作为主方案，自回归 decoder 仅作为后续消融。

4. 模型结构：Transformer Encoder + Parallel Query Decoder

主方法图

历史 IMU patch tokens 进入 Transformer Encoder；`q_0...q_H` 表示当前与未来 horizon queries；decoder 并行输出 `o_0...o_H`，共享 MLP classifier 对每个输出 token 分类。

6. 如何推导切换输出

无需 transition 主类
continue_prob(k) = p(y_{t+k}=y_now) switch_within(k) = 1 - Π p(y_{t+i}=y_now) time_to_switch = first k where argmax p(y_{t+k}) != y_now next_action = first changed label

7. 损失函数与样本构造

样本从连续流中取过去 L 个 patch 作为输入，未来 H 个 patch label 作为 target。

input = X[t-L+1 : t] target = y[t : t+H]

监督目标当前标签 + 未来标签序列交叉熵，可对远期 horizon 降权。

L = CE(y_t) + λ Σ CE(y_{t+k}), k=1..H

8. 后续实验计划

数据 先找连续 HAR 数据验证 future label sequence；UCI HAR 只做 encoder sanity check。
结构消融 early fusion、P2LHAP-style channel independent、hybrid cross-channel fusion。
训练消融 from scratch、masked reconstruction pretraining、future IMU regression。
评价 future accuracy、next-action accuracy、time-to-switch error、calibration。

方向一扩展从 single human label sequence 升级到 `human_action_sequence + phone_motion_sequence`，面向人体动作与手机/相机运动联合预测。
