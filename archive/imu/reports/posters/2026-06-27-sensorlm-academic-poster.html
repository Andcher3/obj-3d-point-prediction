SensorLM: 可穿戴传感器信号的语言语义建模

核心观点：先用层级 caption 构造 sensor-text pair，再联合训练 sensor encoder、text encoder 与 multimodal decoder，使传感器表示支持识别、检索与生成。

对方向一的价值：从“手机 IMU 短窗口分类”走向“人体动作、手机运动、场景语义联合表示”。注意：它不能直接替代标准 HAR 监督分类器。

1. 问题定位

传统 HAR 多是封闭类别分类：sensor -> activity label。SensorLM 转向更开放的目标：sensor -> language-understandable representation。

zero-shot few-shot retrieval captioning

3. 层级 Caption 构造

Statistical 数值摘要

用 mean / max / min / std 等统计量模板化描述总体水平。

Structural 时间结构

检测 increase / decrease / stable / spike / drop，描述局部变化。

Semantic 活动语义

从活动、睡眠、mood 事件记录生成文本，例如 Walk、Outdoor Bike、Sleep。

关键判断：caption 是弱语义监督，不是逐窗口精确 HAR 标签。

Contrastive Flow

  • sensor/text 分别 pool、project、normalize
  • 匹配 pair 拉近，非匹配 pair 拉远

  • decoder 使用 causal mask
  • cross-attention 读取 sensor tokens
  • 预测下一个 caption token

直接启发：分类/检索主要依赖 contrastive alignment；自然语言解释需要 captioning objective。

6. 下游任务如何连接 HAR

Zero-shot Activity Recognition

候选活动写成 prompt，经 text encoder 得到 label embedding；与 sensor embedding 比相似度。

Few-shot / Linear Probing

冻结 sensor encoder，只用每类少量标签训练线性分类器，评价 label efficiency。

Sensor-Text Retrieval

sensor 查 caption，或 caption 查 sensor；R@K 表示正确配对是否进入前 K 名。

Caption Generation

给定 sensor 自回归生成文本；用于解释，不等同于精确动作标注。

8. 必须保留的限制

  • 不是 UCI HAR 式短窗口原始 IMU；输入是一整天 26 维分钟级特征。
  • semantic caption 来自事件记录和模板生成，存在噪声与覆盖不足。
  • 没有在标准监督 HAR benchmark 上直接和 1D CNN / LSTM 比准确率。
  • Zero-shot AUROC 高，但 F1 / BAcc 仍不是成熟分类器水平。
  • 2D patch 依赖 feature 顺序，迁移到手机 IMU 时需重设通道组织。

9. 对后续研究的结论

短期不能直接复现。 当前阶段更适合作为方法路线参考。

中期可借鉴对齐目标。 手机 IMU 可与动作文本、视频事件或运镜语义做 contrastive alignment。

长期价值在开放语义。 对“边走边拍摄、镜头上扬、场景切换”等组合行为更有意义。
