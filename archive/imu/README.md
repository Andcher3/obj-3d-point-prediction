# IMU / HAR / OIS 历史归档

归档日期：2026-09-03

该目录保存此前的 IMU、UCI HAR、SensorLM/SensorLLM、future label sequence、EMA Future Context 和 OIS 短时预测工作。当前项目已经切换为完全基于视频的 MotionForesight 式未来三维轨迹预测。

## 使用边界

- 本目录内容只作为历史记录。
- 当前研究、代码、论文阅读、方法图和汇报默认不引用这些材料。
- 用户明确重新启用 IMU 方向时，再从本目录恢复或读取。

## 主要归档内容

- `workspace/HAR/`：UCI HAR 原始数据。
- `workspace/data/`：UCI HAR 处理结果。
- `workspace/src/`：IMU 数据读取代码。
- `workspace/scripts/`：UCI HAR、SensorLM 和 future-label 材料脚本。
- `workspace/requirements/`：旧课题汇总。
- `reports/literature/`：IMU/HAR/sensor-language 阅读笔记。
- `reports/posters/`：SensorLM、P2LHAP 和 future-label 海报。
- `reports/weekly/`：旧 IMU 方法和组会材料。
- `reports/ideas/`：旧方向一方法构想。
- `AGENTS.pre-2026-09-03.md`、`AGENTS_zh.pre-2026-09-03.md`：切换前的协作说明。
- `research_roadmap.pre-2026-09-03.md`：切换前的 IMU 路线图。
- `progress_log.pre-2026-09-03.md`：切换前的完整进展索引。

为了保留历史链接，旧的逐项进展文件仍保存在 `reports/progress/`，但活动索引 `reports/progress_log.md` 只保留当前视频预测方向。
