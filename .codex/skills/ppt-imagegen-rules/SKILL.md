# PPT Imagegen Rules

Use this skill whenever the user asks to create, revise, or regenerate a PPT, slide deck, paper presentation, group-meeting slides, or slide-style report in this workspace.

## Required Workflow

1. Generate every slide as a full-page image with the image generation tool/skill.
2. Insert those generated full-page images into the PPT.
3. Use existing local PPTs as the visual template for main content slides when available.

## Visual Requirements

- Keep slides information-dense but readable. Avoid sparse layouts and avoid overcrowding.
- Use Microsoft YaHei / 微软雅黑 as the primary font style for both Chinese and English.
- Do not show page numbers unless explicitly requested.
- Do not place a bottom summary bubble on every slide. Use summary callouts only when a slide genuinely needs one.

## Figure Requirements

- Use vector-style diagrams only when they clearly help comprehension.
- Do not overuse vector art.
- If a vector diagram cannot let the audience infer the intended concept without reading the text, do not include it.
- Prefer real examples, paper-style model figures, data-flow diagrams, result tables, and other academically meaningful visuals.
- Do not use content-free labels such as "真实场景示例" or "学术风格插图". Captions and headings must describe the actual content.

## Layout And Heading Requirements

- Do not directly write a module's functional role as its heading.
- For example, avoid using headings like "评价指标解释" for a local bubble or panel.
- Express function through visual hierarchy, grouping, typography, concise content titles, and placement.
