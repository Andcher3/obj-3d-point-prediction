# MotionForesight 概率化未来轨迹预测研究路线

ACTIVE_RESEARCH_SCOPE=VIDEO_MOTION_FORECASTING

日期：2026-09-03

## 1. 研究目标

完全基于观察视频，预测指定物体未来的三维点轨迹分布。

```text
观察视频 V_obs + 目标物体 M_target
-> p(D_future | V_obs, M_target)
```

`D_future` 表示目标物体查询点在未来时段的三维轨迹。任务沿用 MotionForesight 的轨迹表示，避免直接生成未来视频中的背景、纹理与光照等冗余信息，同时保留运动方向、距离、速度、旋转、关节运动和局部形变。

## 2. 核心研究问题

### RQ1：怎样连续地表达多种未来及其概率

目标是学习条件轨迹分布，使模型能够：

- 生成多个合理且有差异的未来；
- 表达不同未来区域或模式的相对概率；
- 在观察条件逐渐变化时，未来分布也连续变化；
- 给出可评测的覆盖率、概率校准和轨迹精度。

固定 `K` 条等权轨迹不能完整表达该目标。`S` 只表示推理时从分布中抽取的样本数。

### RQ2：怎样让宏观语义控制整体未来，让短时运动控制局部细节

希望建立两个时间尺度：

- 全局语义条件：从较长观察范围理解交互对象、可能意图、事件走向和整体运动模式。
- 局部动态条件：从最近若干帧提取速度、加速度、接触、约束、相对位姿和短时物理趋势。

工作假设：

```text
p(D_future | V_obs, M_target)
= integral p(D_future | z_global, c_local, c_geometry)
           p(z_global | c_global) dz_global
```

`z_global` 表示连续的宏观语义/意图变量；`c_local` 表示最近帧的局部动态；`c_geometry` 表示目标点历史与场景几何。该分解用于组织实验，不预先限定具体网络。

## 3. 当前候选路线

### 路线 A：无显式语义的条件轨迹 Flow

```text
目标点历史 + 场景几何 + 最近帧运动
-> Conditional Flow Matching
-> 未来轨迹分布
```

作用：建立概率生成基线，确认多样性、覆盖率和轨迹精度；作为所有语义模块的消融对照。

### 路线 B：显式开放事件语义

```text
观察视频 -> VLM 未来事件候选 -> 事件关系/概率 -> 轨迹 Flow
```

优势：语义可解释，能够描述交互结果和宏观事件。

主要困难：候选召回、幻觉、同义事件合并、事件概率估计、离散事件与连续概率的衔接，以及生成器忽略语义条件。

### 路线 C：连续非文本语义潜变量

```text
长程观察 -> p(z_global | c_global)
z_global + 局部动态/几何 -> 轨迹 Flow
```

优势：更自然地连接连续概率与宏观模式。

主要困难：潜变量可能记忆外观或坐标、缺乏可解释性、模式坍缩、单未来监督和缺少直接语义标签。

## 4. 当前关键困难

1. **单未来监督**：一段视频只观察到一个真实后续，完整条件分布只能依赖跨样本统计学习。
2. **概率含义**：普通 Flow 采样不自动产生易解释、已校准的事件概率。
3. **高维密度**：轨迹维度高，点排列、坐标归一化和有效性掩码都会影响密度定义。
4. **语义监督**：预测时真实未来不可见，显式语义候选本身带有误差。
5. **条件利用**：模型可能使用局部运动获得较低损失，同时忽略宏观语义。
6. **尺度耦合**：宏观语义和局部物理信息需要在不同时间尺度上交互，同时避免互相覆盖。
7. **伪标签噪声**：遮挡、失效点、深度与相机估计误差会被生成模型当作分布的一部分。
8. **评测**：轨迹精度、多样性、分布覆盖、概率校准、语义一致性和物理有效性需要同时评价。

## 5. 分阶段计划

### 阶段 0：固定实验协议

- 确定数据集和许可使用的训练数据。
- 固定观察/预测 horizon、目标指定方式、查询点数量与采样规则。
- 固定坐标系、尺度归一化、可见性和无效轨迹处理。
- 固定单未来与多未来评测指标。

### 阶段 1：复现 MotionForesight 式单未来基线

- 跑通未来轨迹伪标签。
- 跑通训练和推理。
- 复核 ADE、FDE、有效点比例和定性可视化。

### 阶段 2：连续概率多未来基线

- 实现无显式语义的条件 Flow。
- 使用可变 `S` 采样。
- 检查不同噪声是否产生稳定的模式差异。
- 比较精度、覆盖、多样性、校准代理指标与推理成本。

### 阶段 3：宏观语义与局部动态分层

- 明确全局分支和局部分支各自可见的帧范围。
- 明确全局语义变量的监督或自监督来源。
- 通过条件交换、打乱和遮蔽实验检查两个分支的实际作用。

### 阶段 4：概率—语义联合建模

- 比较开放事件语义与连续语义潜变量。
- 检查宏观模式概率是否与轨迹样本占比、邻域质量和真实频率一致。
- 检查语义变化是否主要改变整体轨迹，局部动态变化是否主要改变细节。

### 阶段 5：完整消融与论文问题收敛

- 单未来回归 vs 无语义概率模型。
- 无语义概率模型 vs 显式事件语义。
- 无语义概率模型 vs 连续语义潜变量。
- 只有全局条件、只有局部条件、全局与局部联合。
- 相同采样预算下比较轨迹精度、覆盖、多样性、概率校准和物理有效性。

## 6. 当前最近行动

1. 将“连续概率”具体化为可训练、可读取、可校准的输出量。
2. 画出全局语义分支、局部动态分支与轨迹 Flow 的最小接口图。
3. 整理 MotionForesight 复现所需的数据、代码、权重和评测条件。
4. 设计最小消融，避免在第一个实验中同时加入 VLM、事件图、概率估计和轨迹生成。
