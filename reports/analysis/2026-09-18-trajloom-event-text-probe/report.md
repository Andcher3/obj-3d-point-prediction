# TrajLoom 事件文本条件实验

日期：2026-09-18  
状态：推理、目标区域分析、可视化与本地归档均已完成。

## 目的

检验 TrajLoom 在视觉历史、轨迹历史和随机噪声相同的条件下，能否根据事件级文本系统性地改变未来二维轨迹。实验比较与真实后续相符的事件描述、结果相反的事件描述及无文本输入。

## 协议

- 两个 RoboTAP 视频，历史 81 帧、未来 81 帧，分辨率 832×480。
- Euler 20 步；文本使用 UMT5-XXL pooled embedding。
- 正确文本与相反文本均使用 seed 42、43、44，共 12 次新推理；复用 6 次无文本推理。
- 对形状板正确文本 seed 42 做一次独立复跑；`pred_tracks.npy` 与原结果逐字节一致，SHA256 均为 `db6220a235c1324166d93d78fb4abedc896cf9faed90bc54070f786fe5895d9c`。
- 正确文本根据完整视频人工构造。本实验测试条件控制能力，不模拟预测时的文本生成过程。
- 在 frame 0 人工框选目标区域，并按查询点身份计算目标点指标。

## 结果

### 目标区域 ADE

| 视频 | seed | 无文本 | 正确事件 | 相反事件 | 正确 - 相反 |
|---|---:|---:|---:|---:|---:|
| `10790317943435558913` | 42 | 69.194 | 66.989 | 70.782 | -3.793 |
|  | 43 | 65.205 | 63.197 | 67.374 | -4.176 |
|  | 44 | 66.580 | 64.069 | 68.015 | -3.945 |
| `gear_v2_9-wrist_front_rgb_img-0` | 42 | 169.826 | 166.781 | 176.795 | -10.014 |
|  | 43 | 171.274 | 168.030 | 178.427 | -10.397 |
|  | 44 | 177.031 | 175.583 | 185.787 | -10.204 |

三个种子下，两个视频均满足：正确事件 ADE < 无文本 ADE < 相反事件 ADE。第一段视频中，正确文本还使目标 FDE 相对相反文本降低 8.038、9.060、9.729 px。第二段视频的目标点在终帧不可见，目标 FDE 不可用。

### 文本效应与随机效应

| 视频 | 正确/相反文本平均轨迹差 | 正确文本跨种子平均轨迹差 | 比值 |
|---|---:|---:|---:|
| `10790317943435558913` | 6.980 px | 20.444 px | 0.341 |
| `gear_v2_9-wrist_front_rgb_img-0` | 11.917 px | 36.517 px | 0.326 |

文本产生了跨种子稳定的系统变化，但幅度约为随机种子效应的三分之一。可视化中，正确文本与相反文本的主体运动模式仍高度相似。

### 相对方向

- 形状板视频中，正确文本相对相反文本的平均末端位移变化约为 `(-10.78,+4.13)` px；其中向下变化与“靠近后在画面中下移、变大”的描述一致。
- 绿色柱体视频中，相对变化约为 `(-12.83,+7.69)` px。目标初始位于画面中心右上侧，该变化方向指向画面中心，与正确文本一致。

这说明模型读取了事件文本的关系和结果信息。绝对预测仍主要沿视觉历史给出的运动方向，文本没有把相反描述转化为真正相反的宏观轨迹。

## 判断

TrajLoom 的事件文本条件有效，且效果在三个配对种子上可复现。它可以作为文本条件随机二维轨迹生成的基线或结构参考。

当前证据不足以把 TrajLoom 选为项目第二阶段主干：

- 文本影响弱于随机噪声，未控制宏观事件分支；
- 测试仅含两个视频，正确文本还使用了真实未来信息；
- 模型原生输出二维全场景轨迹，尚未满足指定物体三维轨迹接口；
- 本实验没有轨迹概率、校准、模式覆盖或事件级多分支评价。
