## 1. 当前结论

- Semantic Uncertainty 的后续工作确实扩大了硬语义聚类的表达能力，但需要区分“相似度如何计算”与“已有相似度怎样汇总为不确定性”。
- 对当前“按事件差异组织空间”的需求，条件语义相似度 C-STS 尤其值得关注。CASE（EACL 2026）、CCL（COLING 2025）提供条件化表示学习；它们对当前物体事件的适用性属于本轮推断，尚无本项目实验。
- GePSAn 的任务训练与验证围绕烹饪；AntGPT 的场景覆盖包含 Ego4D，但主要输出受词表约束的动词—名词动作序列；ViNa 依赖历史叙述，具有多候选生成描述，却缺少当前所需的对象级分支验证。
- 候选生成教师继续保持未选定。论文结果、代码入口与在当前任务中足以制作正标签，是不同层次的证据。

## 2. Semantic Uncertainty 后续：关系信息怎样被保留

| 工作 | 核查到的机制 | 输出及对当前需求的意义 |
|---|---|---|
| [Kernel Language Entropy / KLE，2024](https://arxiv.org/html/2405.20003#S3) | 利用双向 NLI 关系构建加权语义图，再以图核及 von Neumann 熵处理候选间的细粒度关系。 | 主要输出一组回答的不确定性。可借鉴软关系与图结构；图建立在已有候选上，尚未直接提供可预测未见未来的模式图。 |
| [Semantic Density，NeurIPS 2024](https://arxiv.org/html/2405.13845#S3) | 用 NLI 的矛盾、中立、蕴含概率近似语义距离，并结合参考回答及生成分数计算单回答的核密度式置信度。 | 第 3.5 节使用的平方距离期望形式为 p_contradiction + 0.5 p_neutral。这是论文中的关系距离构造；NLI 输出并未自动给出已学习且全局一致的欧氏坐标。该置信度也没有直接定义现实未来事件的发生密度。 |
| [Beyond Semantic Entropy / SNNE，Findings ACL 2025](https://aclanthology.org/2025.findings-acl.234/) | 保留簇内和簇间相似度，用近邻熵思想汇总两两相似度；可选相似度包括 NLI、句向量余弦和 ROUGE-L。 | 主要改进不确定性估计的汇总方式。论文未训练一个专用于物体事件差异的新编码器；其任务结果也不说明每一种候选相似度都适合本项目。 |

这些方法在问答等任务上的不确定性效果，尚未验证“拿起/放下”“先打开后关闭/先关闭后打开”等对象事件差异的识别能力。应用前应保留这个证据缺口。

## 3. 更直接相关的方向：条件语义相似度 C-STS

### 3.1 任务为何匹配

[C-STS（EMNLP 2023）](https://aclanthology.org/2023.emnlp-main.345/) 比较两句话在某个明确维度下的相似程度。可以将其抽象为 sim(s1, s2 | c)，其中 c 表示比较关注点，不等同于新增视频输入。

对当前任务的借鉴是让 c 关注目标物体的动作、状态变化或必要的事件顺序。同义改写应接近，动作结果相反的描述应分离。该关注点需要在任务中定义；高相似度、语义等价与属于同一粗模式也应分别验证。

### 3.2 优先比较的表示学习方法

**CASE，EACL 2026。** [正式论文](https://aclanthology.org/2026.eacl-long.231.pdf) 在句子上下文中编码比较条件，减去条件独立出现时的嵌入，再用受监督的轻量投影学习条件相似度。简化表达为 e(s;c)=g(f(c;I(s))-f(c;I(empty)))；此式用于解释论文机制，未指定本项目架构。它输出条件化向量，因此比只提供成对分数的方法更直接对应“表示空间”的需求。[官方代码](https://github.com/LivNLP/CASE)包含嵌入生成及投影训练流程；本轮未运行。

**CCL，COLING 2025。** [论文](https://aclanthology.org/2025.coling-main.306.pdf) 利用条件和相似度标签构造对比学习目标，处理正负样本相似度被过度推高或压低的问题，并平衡难负例与假负例。它适合作为条件编码器训练方法的参考，仍依赖所采用标签的质量。[官方仓库](https://github.com/qinzeyang0919/CCL)已核查入口，未验证训练结果。

### 3.3 相关对照与数据问题

- [Hyper-CL，ACL 2024](https://aclanthology.org/2024.acl-long.41/)：用条件嵌入驱动超网络生成投影，让同一句子在不同比较条件下产生不同表示。属于空间条件化的较早对照。
- [SEAVER，Findings EMNLP 2024](https://aclanthology.org/2024.findings-emnlp.5/)：通过注意力重加权降低无关内容干扰，强调条件相关 token。主要提供条件相似度评分的改进；不直接等于本项目共享模式坐标。
- [Annotating Training Data for Conditional Semantic Textual Similarity Measurement using Large Language Models，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1373.pdf)：修订含混条件，结合人类及 LLM 评分重标注，并在人类复核数据上检验训练收益。它支持使用预训练模型帮助制作语义比较监督，同时也提示现有 C-STS 数据有条件与评分噪声。其结论不直接延伸为“LLM 能标注未发生未来的可行性”。

优先级依据是任务适配性：CASE/CCL 直接涉及条件表示和距离学习；KLE/SD/SNNE 更适合作为后续利用这些关系的参考。这不构成跨论文性能排行榜。尤其 CASE 与其他工作使用的数据版本可能不同，数字应在统一设置下比较。

## 4. 候选生成模型事实复核

### GePSAn

[第 4.1 节](https://arxiv.org/pdf/2310.08312) 的未来步骤任务以 Recipe1M+ 文字食谱预训练，并在 YouCookII 视频上迁移、微调及评估。该任务的已验证范围集中于烹饪；这项判断不等于断言底层预训练编码器只见过烹饪。

它具有多未来下一步骤生成机制，但一步事件的预测没有提供当前所需的目标物体三维轨迹时间接口。保留其跨模态先验迁移思想，不将其当作已验证的开放物体教师。

### AntGPT

依据[正式版本第 3.1、4.1 节与附录 C.1](https://arxiv.org/html/2307.16368)：

- 场景覆盖包括 Ego4D、EPIC-Kitchens-55、EGTEA Gaze+。后两者围绕厨房活动；Ego4D forecasting 部分跨多个日常活动场景，因此“只限厨房”不符合其全部实验。
- 输出以动词—名词动作标签为主。附录明确处理超出标签词表的输出，所以开放语言模型并不等于已验证开放事件输出。
- Ego4D 评测为未来 20 个动作、5 条候选序列的最小编辑距离；这属于事件步数协议，并非每个固定时刻的物体状态预测。其他数据集还采用后续动作集合预测。
- 其标签可涉及拿起、打开等人—物交互；它研究人类行为及其目标，未验证任意指定物体或非人主导的自然运动预测。

### ViNa

依据[第 4.1、4.6.1–4.6.3 节](https://arxiv.org/html/2503.01416v1)：

| ViNa-GPT2 的验证集输入 | ROUGE-L |
|---|---:|
| 仅真实历史叙述 | 31.04 |
| 仅视频 | 21.87 |
| 视频 + 真实历史叙述 | 31.85 |
| 视频 + LaViLa 预测历史叙述 | 25.52 |

这些结果支持用户关于历史文字依赖的判断；AI 生成叙述并未消除性能下降。上述数值来自表 5、表 6，作为原论文消融证据，不成为本项目参数或验收门槛。

- **多个未来分支：** 第 4.6.1 节提到 nucleus sampling 与 50 个候选输出。原模型具有多输出生成设置；论文没有直接验证这些输出是否为去重后的不同对象事件分支。单个输出中的多条连续叙述，也应与多个替代输出区分。
- **预测对象：** 任务面向 Ego4D 日常人类活动，文本包含人—物及物—物关系。它超过单纯人体姿态描述，但原接口未验证针对任意指定物体输出开放运动模式。
- **时间尺度：** 数据构造为观察 48 秒并描述未来 48 秒，通常约 20 条未来叙述。当前项目尚未固定最终时间范围；应对齐事件标签与轨迹预测时段，仅调整文字长度不足以说明已经完成时间适配。
- **有 caption 的数据：** Ego4D 本身已有人工叙述。给教师的历史叙述应与已观察前缀对齐。训练期使用这些文字可作为候选教师方案，但学生推理仍为纯视频时，文字优势能否迁移尚需验证。若推理阶段也依赖外部真实历史文字，则输入条件已经扩展。

结论：ViNa 可保留为“有高质量历史叙述时的待检验教师”，不视为已找到的纯视频开放物体多未来教师。
