# 伪分布监督、随机条件与对抗训练详细设计

日期：2026-09-04  
状态：方法候选，所有模块与权重均待独立实验

## 1. 直观目标

对一段观察视频，模型先输出一张“未来可能性地图”。地图中的每座山峰代表一种宏观未来，山峰覆盖的面积与高度共同决定该模式的概率质量。随后，模型从每座主要山峰取出一个模式变量，再结合最近帧速度、接触和目标几何，生成该模式下的精细三维点轨迹。

例如，观察到手接近并接触杯子时，广域动作先验可能提供“抬起、横向移动、倾斜、保持原位”等候选。长程语义判断交互目的和场景关系，最近帧动态排除与当前速度或接触状态矛盾的候选。最后留下若干概率不同的模式，每个模式内部还能产生速度、路径和终点略有差异的轨迹。

## 2. 三层结构

### 第一层：广域运动潜空间

训练轨迹编码器 `E_motion` 和连续解码器 `G_motion`：

```text
z = E_motion(D_future)
D_recon = G_motion(z, c_geometry)
```

`z` 表达整体运动类型、方向、终点和交互结果。训练数据可以来自目标数据集、MolmoMotion 类大规模三维点轨迹数据，以及通过可靠流程转换得到的外部轨迹。轨迹先转换到统一参考坐标和目标中心尺度，减少相机、物体位置和大小占据潜变量。

与 MotionMap 的 codebook 不同，`G_motion` 可以解码连续坐标，不要求 `z` 必须对应训练集中某个格点。二维空间可以作为最早的可视化原型；容量不足时再扩展为更高维潜变量，二维图仅显示投影。

### 第二层：宏观未来概率图

长程视频编码器提取 `c_global`；最近帧只向概率头提供一个低带宽的物理可行性摘要 `g(c_local)`，概率头预测：

```text
p_theta(z_mode | c_global, g(c_local), c_geometry, target)
```

该分布回答“接下来整体可能怎样发展”。`c_global` 负责主要语义选择，`g(c_local)` 只负责降低与当前速度、接触或几何明显矛盾的模式。完整的高时间分辨率局部特征仍留给第三层，避免它绕过宏观语义直接决定全部未来。局部极大值是候选模式，模式概率使用峰值吸引域内的概率质量：

```text
P(mode=m | x) = integral_{z in B_m} p_theta(z | x) dz
```

这样可以直接选取高概率模式，无需先随机生成大量轨迹再聚类。

### 第三层：模式内轨迹细化

对每个宏观模式加入模式内噪声 `epsilon`：

```text
D_hat = G_detail(z_mode, epsilon, c_local, c_geometry)
```

- `z_mode` 控制抬起、滑动、倾斜等整体差异；
- `epsilon` 控制同一模式内部的细微变化；
- `c_local` 控制起始速度、加速度、接触时刻和短距离走势；
- `c_geometry` 控制点间结构、尺度、可见性和场景约束。

Stochastic Conditioning 主要用于这一层，防止 `G_detail` 只依赖局部条件而忽略 `epsilon`。宏观多模态已经由第二层概率图负责，无需让一个噪声同时承担模式选择和局部细节两种任务。

## 3. 能否把未来分布作为真值

可以构造并监督一张未来分布图，但它的性质取决于来源。

### 真实分布真值

只有在近似相同条件下重复观察到许多独立后续，或者可控模拟器能够重复运行同一初始状态时，经验频率才接近真实条件概率。

### 伪分布真值

普通视频每个前缀只有一个真实后续。此时可以像 MotionMap 一样，通过其他样本和先验构造：

```text
q_target(z | x)
= Normalize[
    K(z, z_real)
    + sum_j r_j K(z, z_candidate_j)
  ]
```

- `z_real`：当前视频真实后续，确定为正支持；
- `z_candidate_j`：相似观察的真实后续或预训练模型候选；
- `K`：在潜空间形成平滑概率山峰的核函数；
- `r_j`：候选可信度。

候选可信度由不同因素组成：

```text
r_j = r_source · r_semantic · r_dynamic · r_geometry
```

- `r_source`：真实检索轨迹通常高于纯生成候选；
- `r_semantic`：动作、对象、交互关系是否匹配；
- `r_dynamic`：候选起始速度与当前动态是否连续；
- `r_geometry`：点结构、接触和空间约束是否可迁移。

这些系数和核宽度都不能直接指定固定数字，需要验证集和校准集确定。

## 4. 支持图与概率图分开

外部大模型最容易告诉我们“哪些动作可能存在”，较难给出“当前场景下各动作的真实频率”。因此内部可分成两张图：

```text
A(z | x)：可行性/支持图
P(z | x)：经过真实数据校准的概率图
```

- 真实后续、检索未来和大模型候选共同训练 `A`；
- 相似真实条件下的经验频率主要训练 `P`；
- `A` 限制候选范围，`P` 在该范围内分配概率；
- 数据不足的区域保留“低置信度”，不把大模型偏好包装成真实概率。

这种分离允许外部先验增加新模式，同时保留概率校准对真实数据的依赖。

## 5. 分布监督损失

若第二层输出归一化热图，可采用：

```text
L_map = CE(q_target, p_theta)
```

或：

```text
L_map = KL(q_target || p_theta)
```

若使用连续可计算密度，则对真实未来保留：

```text
L_nll = -log p_theta(z_real | x)
```

两者可以同时存在：伪分布提供多模式形状，真实后续似然保证观测到的未来不会被压低。对来源不可靠的候选，应降低分布监督权重或只进入支持图。

## 6. 判别器可以做什么

### 轨迹真实性判别器

```text
D_real(D, object_geometry)
```

它检查生成轨迹是否像真实运动，包括平滑性、点间协同、刚性或关节结构和速度变化。该判别器可以使用所有真实轨迹训练，不需要同一观察拥有多个后续。

### 条件兼容判别器

```text
D_compat(V_obs, target, D)
```

它检查轨迹是否与当前观察相容。正样本包括原始真实配对和经过严格筛选的等价观察—未来配对。负样本应使用明确冲突的情况，例如起始位置断裂、速度方向严重矛盾、接触关系不可能或语义事件互斥。

不能把“当前视频没有发生的未来”全部交给判别器作为假样本；其中可能包含合理反事实，这会把模型重新推向单一未来。

### 模式一致性约束

可以训练辅助预测器从生成轨迹恢复 `z_mode` 或宏观事件，使不同峰值确实生成不同整体模式。这类互信息或循环一致性约束比直接最大化任意两条轨迹的距离更稳定。

## 7. 多样性损失怎样使用

直接最大化两条轨迹之间的距离容易产生夸张位移和物理错误。建议把多样性限制在有效支持域中：

- 不同宏观峰值的轨迹应有明显的终点、方向或交互结果差异；
- 同一峰值内部只要求 `epsilon` 对局部细节产生可测影响；
- 达到模式分离阈值后停止奖励继续远离；
- 只有通过真实性与条件兼容检查的轨迹才计算多样性奖励。

Stochastic Conditioning、模式恢复约束和受限排斥损失可以组合，但应分别做消融。

## 8. IS、判别器分数和评测指标

Inception Score 原本依赖图像领域的预训练分类器，评价生成图像的类别清晰度和总体类别多样性。它通常是评测指标，不是主要训练损失。当前三维点轨迹任务没有天然的 Inception 分类器，直接套用 IS 缺乏明确含义。

可以训练或冻结动作/轨迹编码器，构造类似指标，但应称为轨迹域指标，并同时报告：

- **质量/精确率**：生成轨迹中有多少位于真实运动流形；
- **覆盖/召回率**：真实或伪分布中的模式有多少被覆盖；
- **条件一致性**：轨迹是否符合观察视频、目标和局部动态；
- **模式校准**：预测概率与等价条件下的经验频率是否一致；
- **轨迹误差**：ADE、FDE、代表轨迹误差和 `best-of-S`；
- **物理有效性**：速度连续性、点结构一致性、接触和几何约束；
- **潜变量利用**：改变 `z_mode` 与 `epsilon` 是否分别改变宏观模式和局部细节。

单一 IS 式分数无法同时判断真实性、覆盖、条件匹配和概率校准。

## 9. 建议训练顺序

### 阶段 A：训练运动潜空间

训练 `E_motion/G_motion`，先验证轨迹重建、插值、跨对象迁移和几何一致性。

### 阶段 B：构造伪分布并训练概率图

只训练 `p_theta(z|x)`，比较单峰真实未来、MotionMap 式数据检索、多来源先验三种监督。

### 阶段 C：训练模式内随机细化

固定宏观模式，加入 `epsilon` 和 Stochastic Conditioning，检查同模式内部是否产生合理变化。

### 阶段 D：加入判别器

先加入轨迹真实性判别器，再单独评估条件兼容判别器。检查稀有模式是否被判别器压制。

### 阶段 E：概率校准

在多后续数据、等价条件组或可控模拟数据上校准模式概率。此前输出只称模式置信度或伪分布质量。

## 10. 最小消融

| 版本 | 分布监督 | 模式内随机 | 判别器 | 用途 |

| A | 单真实未来 | 无 | 无 | 条件密度基线 |
| B | 数据检索伪分布 | 无 | 无 | 对照 MotionMap 思路 |
| C | 数据检索 + 外部先验 | 无 | 无 | 检验支持域扩展 |
| D | C | Stochastic Conditioning | 无 | 检验模式内变化 |
| E | C | Stochastic Conditioning | 真实性判别器 | 检验运动质量 |
| F | C | Stochastic Conditioning | 真实性 + 条件兼容 | 检验当前视频一致性 |

每次只增加一个因素，所有损失权重、核宽度、潜变量维数和模式阈值都通过实验确定。

## 11. 当前方法主线

```text
广域真实轨迹/预训练模型
-> 连续运动潜空间与支持先验

当前长程视频
-> 语义与交互状态
-> MotionMap 式宏观未来概率图
-> 局部极大模式及概率质量

每个宏观模式
+ 最近帧动态
+ 目标与场景几何
+ 模式内随机变量
-> 多组精细三维点轨迹

真实轨迹似然 + 伪分布监督
+ 随机变量利用约束
+ 轨迹真实性/条件兼容约束
-> 训练
```

这套结构保留“直接预测未来分布并读取高概率模式”的核心，同时明确区分真实后续、伪分布、生成先验和概率校准。
