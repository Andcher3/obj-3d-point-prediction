## 3. 最新 FlowForesight 主干

### 3.1 任务接口

```text
输入：前 7 帧单目视频 + SAM 目标掩码 + 64 个目标查询点
监督：完整 22 帧视频离线生成未来 15 帧三维点轨迹伪标签
输出：S 组候选未来，每组形状为 64 × 15 × 3
坐标系：最后一个观察帧的相机坐标系
```

其中 `S` 是推理采样预算，不是模型结构常数。现有方法图和部分发言稿仍写 `K=6` 或“六路输出”，这是展示示例；后续正式文档应统一改成可变的 `S`。

### 3.2 观察条件

- `C_point`：查询点在观察期的三维位置、位移、局部特征、可见性等点级历史条件。
- `C_scene`：观察期 RGB、深度/pointmap、相机信息形成的视觉—几何场景条件。
- 未来帧只用于离线产生训练伪标签，不进入推理条件编码器。

### 3.3 生成训练

对真实未来轨迹 `D_gt` 与高斯噪声 `Z` 做 Flow Matching：

```text
D_s = (1-s) Z + s D_gt
u*  = D_gt - Z
v_theta(D_s, s | C_point, C_scene) -> u*
```

训练目标是学习给定观察条件后的未来轨迹条件分布。每个视频样本只提供一个实际发生的未来，因此多模态性依赖数据集中相似过去对应的不同后续，不能据此宣称模型覆盖了所有反事实未来。

### 3.4 推理输出

观察条件只计算一次，再从不同高斯初值出发重复求解 Flow，得到 `S` 组完整轨迹样本。当前输出表达的是“多个候选未来”，还不等同于校准后的不确定性估计：

- 没有事件类别概率；
- 没有置信区间或概率校准；
- 不保证不同噪声一定产生互异模式；
- 暂未区分数据本身的多义性与模型认知不足。

因此，现阶段更准确的表述是“随机多假设未来轨迹生成”或“未来分布采样”。

## 4. 语义引导构想到了哪一步

语义引导确实讨论过，但没有进入最新主干。

### 4.1 显式事件语义分支

曾设计过下面的流程：

```text
观察视频
-> VLM 多次生成少量完整未来事件假设
-> 开放词汇事件记录
-> 等价 / 蕴含 / 兼容 / 互斥关系图
-> 事件语义编码
-> 作为条件引导轨迹 Flow
```

相关修订包括：

- 放弃 `APPROACH`、`CONTACT` 等固定事件词表，改为固定字段、开放内容的事件记录。
- 只有等价事件可合并；兼容事件只作为关系属性，不能被合并成同一分支。
- 候选支持度应按多次独立回答的复现情况统计，不能用同一回答列表内的频数解释为概率。
- 曾提出教师语义预训练、预测语义对齐、互斥语义排序损失、条件 dropout 和语义交换测试，以检查 Flow 是否真正使用语义条件。

该分支仍有明显问题：事件候选召回与幻觉、语义类边界、单一真实未来监督造成的选择偏差、Flow 忽略语义条件、测试时语义支持度估计，以及语义与轨迹的一致性验证。

### 4.2 非文本未来潜变量分支

还推演过用冻结视频编码器从真实未来提取小容量潜在交互状态，再由观察前缀预测潜变量分布，并用潜变量条件控制轨迹 Flow。文本只负责事后解释。该方案尚未确定连续潜变量还是 VQ 码本，也没有完成诊断实验。

### 4.3 最新取舍

2026-08-05 的方法图和 2026-08-06 方法发言稿采用了更小的主线：

```text
C_point + C_scene + Conditional Flow Matching -> S 组未来三维点轨迹
```

其中 `C_scene` 可以包含视觉特征中的隐式场景信息，但当前没有语言事件、事件图、事件概率或显式语义控制。显式语义引导被保留为后续研究变量。

## 6. 恢复工作时的推荐顺序

1. 固定研究定位和最小任务协议：数据集、7/15 帧划分、目标掩码来源、64 点采样、坐标归一化、有效性规则。
2. 先复现单未来 MotionForesight 基线，确认伪标签与 ADE/FDE 评测链条可运行。
3. 实现无显式语义的最小 FlowForesight，仅使用 `C_point + C_scene`，用 `S∈{1,3,6,12,24}` 比较误差、覆盖、多样性和推理代价。
4. 检查不同噪声是否真正形成模式差异；若只产生相近轨迹，先处理生成退化与数据覆盖，不急于加入语义模块。
5. 在最小主干稳定后，再把语义作为独立消融变量。建议先测试简单的观察期连续语义特征，再测试开放事件图，避免一次引入候选生成、聚类、图关系和概率估计四类误差。
6. 将现有方法图与发言稿中的固定“6 路”统一为可变 `S`，补齐第 4—5 页方法图片。
