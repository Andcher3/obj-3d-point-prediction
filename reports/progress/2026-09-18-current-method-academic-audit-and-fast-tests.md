# 当前整体方法的学术合理性审核与快速验证计划

日期：2026-09-18

## 方法定位

当前版本适合作为“语义多分支到确定性稠密三维轨迹”的第一版研究系统：第一阶段以具有世界知识的 VLM 顺序生成多个未来 narration；第二阶段恢复 MotionForesight 的文本 cross-attention，使每条 narration 条件化一条未来三维点轨迹。

它尚未实现连续轨迹分布、同一 narration 下的模式内随机性或校准概率。因此，当前版本可以验证语义候选覆盖和文本到轨迹的可控接口，不能单独承担项目原定的 probability-continuous future uncertainty 主张。

## 主要学术风险

### 1. 长尾覆盖是当前假设，不是概率主张

当前方法不声称输出每条 narration 的真实发生概率。相对独立重复采样，顺序记忆和 EMTA 有希望减少常见模式的重复占位，让固定候选预算覆盖更多罕见模式。ModeSeq 原文支持模式覆盖改善，没有专门证明长尾事件召回；本项目需要在按训练频率划分的 head/medium/tail 事件上报告固定预算的 recall@S、unique-mode coverage 和重复率。

### 2. 跨分支记忆改用实际生成 token

为避免独立 mode embedding 与随机文本脱节，第 `k` 个分支直接读取此前实际生成的 narration token，并用替代未来边界 token 区分各候选。候选结束位置的 hidden state 作为置信度和候选表示。该实现保证 memory 对应实际输出，但需验证模型是否把前序文本理解为替代候选而非连续动作，并控制上下文长度和复制倾向。

### 3. 双向蕴含不完全等于事件模式等价

双向 NLI 适合识别同义表达，但容易受对象指代、时间窗口、描述粒度、动作包含关系和顺序影响。它可以作为 Match 函数，必须先用本任务人工标注句对校准；NLI 低分不能自动解释为两个合理且不同的未来。

### 4. 文本条件的可辨识性不足

第二阶段训练三元组中，视频和 narration 同时指向同一个真实未来。模型可能只靠视频降低轨迹损失，忽略 narration。可在完整视觉样本之外混合保留目标几何与近期运动的视觉模态 dropout，并增加轨迹--文本匹配辅助损失；训练时的视觉削弱不能替代文本置换和反事实控制测试。

### 5. 使用第一阶段预测 narration 训练第二阶段

先训练并冻结第一阶段，再用其自由生成候选训练第二阶段，可显著减小文本分布差异。训练时只有与真实 future narration 达到双向蕴含阈值的预测候选才能和该样本 `X_GT` 配对；其他替代候选没有该场景下的三维真值。无匹配样本需要回退 GT narration 或跳过。该流程仍需报告 oracle、matched prediction 和完整 prediction 的差异。

### 6. Ego4D 文本与目标轨迹可能错位

Ego4D narration 可能描述佩戴者或其他物体，时间戳也不是精确动作边界。目标对象、未来窗口、文本和三维伪轨迹必须形成可审核的统一样本；否则第一、二阶段可能在学习不同事件。

### 7. 贡献可能被理解为已有模块组合

MotionForesight 式前瞻适配、ModeSeq、双向 NLI 和 Wan 文本 cross-attention 都有来源。论文需要围绕可证伪问题组织贡献：顺序语义模式建模是否在单未来监督下提高事件覆盖、降低重复，并且这些语义分支是否能稳定控制指定物体的稠密三维未来。只有模块拼接和定性案例不足以建立方法贡献。

## 快速验证顺序

### A. 无训练或极少计算，当天可做

1. **数据可用性审计**：随机抽取约 100 个候选窗口，人工标注 narration 是否对应目标对象、是否落在统一未来窗口、是否包含可区分事件、三维伪标签是否有效。报告可用率和主要淘汰原因。
2. **NLI Match 校准**：构造同义、单向包含、动作顺序变化、对象变化、互斥未来和粒度差异句对；由人工给出事件等价标签，评估双向蕴含的 AUROC/F1，并只在该集合上选择 `tau`。
3. **VLM 先验探针**：在 30--50 个视频上固定相同输出预算，比较独立 token sampling 与前序候选 token memory。人工统计目标相关性、GT 覆盖率、事件唯一数、重复率、幻觉率，并按事件频率报告 tail recall。该实验先验证顺序文本条件是否有潜力。
4. **现有伪轨迹抽查**：渲染少量目标点历史与未来伪标签，检查漂移、深度跳变、遮挡失效和目标外点比例，避免把标签噪声误判为多未来。

### B. 小规模过拟合或接口实验，约一至两天

5. **第一阶段 branch-use 测试**：在固定 seed 或 greedy decoding 下，分别使用正常前序 token、清空前序 token、打乱候选顺序和跨视频交换前序候选。若输出几乎不变，说明 decoder 没有利用候选 memory。记录候选间 NLI 重复率、GT match@S、各分支成为 `k*` 的频率和跨 seed 分配稳定性。
6. **EMTA 小样本消融**：在小数据子集上比较独立分支、顺序 memory、顺序 memory+EMTA。检查 EMTA 是否降低重复且不降低 GT match@S；同时观察是否所有样本长期只选择固定分支。
7. **第二阶段文本通路单元测试**：用同一个观察 latent 配对少量人工的 `left/right/static` 文本和对应简单轨迹，训练 cross-attention LoRA 过拟合。检查文本 context 是否改变输出、LoRA 是否获得非零梯度、模型能否在相同视觉输入下按文字选择不同轨迹。它只证明接口可学习，不作为真实任务结果。
8. **真实数据短程消融**：在小子集短训 `正确文本 / 空文本 / 打乱文本` 三个版本或条件。正确文本若没有改善误差或文本置换没有稳定改变宏观运动，优先检查文本条件路径，暂不加入随机 mask。

### C. 完整训练前必须保留的验证

9. **oracle--predicted gap**：第二阶段分别输入 GT narration、第一阶段预测 narration 和空文本，量化阶段接口损失。
10. **文本干预测试**：同一视频输入同义改写、动作顺序变化、目标对象变化和明确冲突文本。同义改写应近似不变；事件变化应主要改变宏观方向、终点或交互结果；局部起点和历史边界应保持稳定。
11. **完整消融**：单轨迹 MotionForesight、文本条件但单 narration、独立多 narration、ModeSeq memory、ModeSeq+EMTA。这样才能区分 VLM 先验、顺序建模和 EMTA 的实际贡献。

## 最优先的四项

优先执行数据可用性审计、NLI Match 校准、第一阶段 branch-use 测试和第二阶段文本通路单元测试。它们分别验证数据、匹配器、多分支机制和阶段接口，成本较低，并能尽早否定最关键的结构假设。

## 判断标准

- 第一阶段可信：目标相关候选稳定、GT match@S 提升、语义重复下降，并且 mode memory 消融造成可重复的性能退化。
- 第二阶段可信：正确文本优于空/打乱文本，同义文本轨迹近似一致，事件变化能控制宏观运动，同时保留历史边界与局部几何。
- 完整方法可信：predicted narration 相对 oracle 的退化可测且可接受；各组件消融分别支持其声称的作用。
- 当前版本仍不能证明：连续轨迹概率、替代未来的真实概率、同一 narration 内的运动分布或概率校准。
