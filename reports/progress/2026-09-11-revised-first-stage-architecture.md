# 第一阶段架构重评：语义前瞻模型、ObjectForesight 多结果与 ModeSeq

## 结论

round3 只否定了“L1 latent 随机扰动 + SemDiD 反馈”这一具体候选生成实现，不能否定第一阶段的总体目标。分享对话中的方案不是把顺序概率公式单独拿来替换旧方案，而是组合三类互补假设：

1. MotionForesight：把完整视频上的回顾式模型改造成只看视频前缀的未来语义预测器；
2. ObjectForesight：在语义未来 latent 上学习条件生成分布并采样多个结果；
3. ModeSeq：在单未来监督下按序生成 mode，并用 early-match/互补性机制减少重复。

## 与旧实现的结构差异

旧实现：

```text
L1 latent 局部随机扰动 -> L1 文本前瞻 -> SemDiD/NLI 去重与反馈
```

分享对话中的实现意图：

```text
完整未来视频 -> 回顾式语义/意图表示（离线目标）
观测前缀     -> 前瞻式语义预测器 p(y_future | V_obs)
             -> ObjectForesight 风格的多结果生成
             -> ModeSeq 风格的顺序模式解码与互补约束
             -> SemDiD 作为事件等价/关系判定
```

核心变化是：模式在语义预测空间中被直接生成，L1 不再承担“靠随机扰动发现新模式”的职责。这样与第一阶段目标更对齐，也解释了为什么不能用 round3 结果直接否定该路线。

## 三个来源各自能回答的问题

| 来源 | 可迁移的理论依据 | 不能自动保证的内容 |
|---|---|---|
| MotionForesight | 通过未来遮挡、离线未来目标和轻量适配，将回顾式视频模型转为前瞻预测模型；保留预训练时序/语义先验 | 需要真正的因果遮挡训练；原模型的回顾表示不一定天然是未来模式表示 |
| ObjectForesight | 连续 latent 生成器可以表达条件多结果，避免手工在一个 latent 周围加噪声 | 多个样本不必然对应多个事件模式，也不自动产生校准的离散模式概率 |
| ModeSeq | 顺序生成让后续 mode 知道已覆盖内容；EMTA 在单真值下抑制重复、改善候选互补性 | 不能凭单真值识别所有未发生模式；原始轨迹距离和 EMTA 需改写为语义模式匹配 |

因此，这些工作确实能部分回答此前的疑问：它们分别提供了前瞻接口、多结果生成和单真值下的模式区分机制。它们依赖的是额外结构假设，不是对真实多模态分布可辨识性的证明。

## 迁移后仍必须明确的四点

1. **语义目标**：完整未来视频要编码成事件/意图级 `y_future`，不能只是完整视频摘要或表面文字。需要验证同义表达映射到同一模式、不同事件落在可分区域。
2. **ModeSeq 的实际接入**：若只是独立采样后再用 SemDiD/NLI 排序，仍然是旧式后处理。要让第 `k` 个模式在生成时看到已生成的模式，并把 early-match/互补性写入训练或解码目标。
3. **无序模式集合**：模式生成顺序是计算顺序，不是事件发生顺序。需要规范排序、集合损失或置换不变训练。
4. **概率解释**：ObjectForesight 样本频率或 ModeSeq confidence 不能直接称为 `p(mode|V_obs)`。若保留概率创新，需要明确密度/模式质量的定义并单独校准；若当前阶段只验证候选模式，则先报告排序和覆盖，不宣称概率已成立。

## 建议定位

将 L1+SemDiD 随机分支保留为已测基线；把“回顾式语义模型的前瞻化 + ObjectForesight 风格语义 latent 生成 + ModeSeq 顺序互补解码”作为新的第一阶段主线候选。SemDiD 继续负责语义等价与关系标注，可作为训练辅助和评估器，而不再负责弥补生成器没有发现新模式的问题。
