# 联合时空关系解码器探索实验

- 日期：2026-09-27
- 性质：四段既有 Ego4D 视频的探索性架构对照；方案和判断信号在训练前固定。
- 协议：`configs/surface_relation_joint_decoder_probe_2026-09-27.json`
- 实现：`scripts/surface_relation_joint_decoder_probe.py`
- 完整结果：`experiences_results/surface-relation-joint-decoder-probe-2026-09-27/results.json`；40 个训练模型参数保存于同目录 `trained_folds.pt`。

## 问题与协议

检验观测图上的跨点交互能否在冻结 MotionForesight 的预测表示之后，改善整个物体的未来点轨迹。比较冻结原始输出、联合关系解码器、无跨点消息的等参数逐点解码器；两个可训练模型均为 5,043 参数，共享物体状态、时间卷积、损失和优化预算。关系版以 2D 对称 kNN `k=3` 对邻点交换消息，联合输出坐标残差；逐点版用自身时间摘要替代邻点消息。两者均不使用逐边独立预测、图积分或幅度门控，不强制边长固定。残差在全部 query 上中心化，因此不能修正物体质心的共同位移。

四折整视频留一，训练视频各用未来槽位 0–6 的伪标签训练、7–8 验证；被留出的整段视频用 0–8 测试。每个配置 5 个初始化种子、400 步，不根据留出视频标签选择 checkpoint。训练损失各占一半：去质心点位 MSE 和有效边三维向量 MSE。输出侧的结构误差分别测去质心点误差、三维边向量误差，另以绝对 ADE 监控轨迹是否恶化。以视频为独立单位，预设信号为关系版在至少 3/4 视频的两项结构误差均优于 baseline 和逐点对照，且 ADE 至多高于 baseline 5%。

观测特征使用已缓存的 MotionForesight 输出 `P0,H` 和只看观测期 TrackCraft3R 的 3D 历史；图由观测时刻 query 的 UV 构造，保留全部 48 个节点。监督使用完整视频 TrackCraft3R 的未来位移，在同一 query 的观测 `t0` 处锚定。未来有效性仅过滤训练损失与评测，不进入图和模型前向。相关标签仍是伪标签；此锚定只消除 `t0` 的静态点位差异，不验证未来运动的真实精度。

## 结果

下表为每视频 5 个种子的中位数；括号依次为原始 baseline / 逐点解码 / 关系解码。去质心及边误差以各自视频的目标尺度归一化，ADE 单位为米，均越低越好。

| 留出视频 | 去质心点误差 B / N / R | 边向量误差 B / N / R | 绝对 ADE B / N / R |
| --- | ---: | ---: | ---: |
| `6516` | 0.1861 / 0.1585 / 0.1698 | 0.1363 / 0.1294 / 0.1259 | 0.10539 / 0.10676 / 0.10735 |
| `4d05` | 0.0464 / 0.0698 / 0.1552 | 0.0421 / 0.0787 / 0.1057 | 0.02880 / 0.04268 / 0.08600 |
| `9069` | 0.0127 / 0.0233 / 0.0255 | 0.0156 / 0.0231 / 0.0257 | 0.01489 / 0.02464 / 0.02585 |
| `cb78` | 0.0253 / 0.0262 / 0.0305 | 0.0228 / 0.0234 / 0.0263 | 0.01544 / 0.01569 / 0.01675 |

关系版在 `6516` 的两项结构误差比 baseline 分别低约 8.7% 和 7.6%，ADE 高约 1.9%；逐点版在这个视频的去质心误差更低。另三视频上关系版的两项结构误差与 ADE 均高于 baseline。因此预设的**同时胜过 baseline 与逐点版、并满足 ADE 约束**为 **0/4 视频，未通过**。各视频的 5 个种子只反映初始化敏感性，不能当成 20 个独立视频。

训练视频的槽位 7–8 验证损失，两个解码器分别约为同一数据上 baseline 损失的 0.12–0.32 倍；但解码器的验证损失约为自身训练损失的 10–13 倍。不同时间段难度可能变化，单凭该比值不能定性为过拟合。更直接的现象是：同视频较晚时段的验证改进没有转化为未见视频的稳定收益，尤其 `4d05` 的关系解码退化显著。

## 检查与解释边界

- 全部 40 个训练任务正常完成，输出有限；各模型初始修正为精确零，梯度有限。查询点重排检查的最大差异处于浮点误差量级；改变未来有效性不会改变前向输出。
- 四个观测图分别有 85、88、86、87 条边；训练监督有效 query 分别为 47、48、48、48。未来有效性不参与构图。
- 关系版和逐点版参数量完全相等，但输入归纳偏置不同；结果只检验本次具体的跨点消息机制与冻结输出接口。残差被强制去均值，因此本次实验没有检验可学习的物体级平移修正，也没有检验生成期可训练接口。
- 四段视频此前已参与 F2 方法探索，存在设计选择后的再使用；标签是完整视频推得的 TrackCraft3R 伪轨迹，缺乏独立真实轨迹验证。该实验不能证明所有联合关系建模或软关系假设失效，也不能凭训练视频验证损失证明跨视频有效。
- 已按统计解释检查 11 类问题：重点风险为既有视频上的多次架构探索（选择路径与多重尝试）、按 seed 伪增样本量，以及将视频级平均外推为普遍结论；未做显著性检验，不作因果或泛化宣称。

本次具体实现没有展示跨视频稳定收益。后续设计判断应从监督可靠性、冻结表示的跨视频迁移和当前消息构造入手；本实验不支持继续调幅度阈值来掩盖预测误差。
