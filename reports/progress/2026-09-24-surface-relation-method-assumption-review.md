# 点间关系方法假设与后续决策复核

- 日期：2026-09-24
- 状态：关系假设保留为研究假设；当前 pseudo-GT 与 Relation Head 训练仍未放行

## 单上下文结果判断

- 单一 16 帧 TrackCraft3R 坐标链可以生成未来边位移和形状关系候选，但这只证明目标可计算，不证明目标可靠。
- `48/48` query 有效，t0 匹配误差中位数为 `0.60 px`，最大值为 `67.70 px`。该异常点可能污染相邻边，必须先建立 anchor validity mask。
- 未来边位移变化中位数为 `0.028 m`、p90 为 `0.136 m`；规范化形状变化中位数为 `0.264`、p90 为 `1.184`。对近似刚体目标而言，这些变化不能直接解释为真实物体形变，仍可能包含深度或跟踪误差。

## 方法假设状态

| 假设 | 当前状态 |
|---|---|
| 同一目标的点之间存在可利用的相关运动 | 保留，属于问题动机与待验证假设 |
| 点间关系应作为硬刚体约束 | 否定；应采用时变、软约束 |
| 跨 DA3/TrackCraft 上下文可直接登记绝对 3D pseudo-GT | 已被五视频审计否定 |
| 单一上下文能生成关系候选 | 部分支持，仍需逐点质量审计 |
| 2D symmetric kNN `k=3` 可作为观测图候选 | 仅支持连通性与工程可用性，未证明语义邻接正确 |
| `H_output` 包含可学习的点间关系信息 | 尚未测试 |
| Relation Head + graph integration 能改善 MotionForesight | 尚未测试 |

## 后续决策

1. 不启动真实 pseudo-GT 上的 Relation Head 训练。
2. 对五个视频生成单上下文目标，并加入 anchor 误差阈值、异常点屏蔽、未来投影/可见性检查和刚体/铰接分层统计。
3. 用去除异常 query 后的有效图重新检查连通性与边数量；不得为了通过闸门事后挑选阈值。
4. 先在合成、oracle 或 E1 受控目标上完成 Relation Head 的梯度和 integration probe。
5. 若单上下文目标在刚体样本仍有大形状漂移，停止把该 pseudo-GT 用作关系监督，转向关系不变量诊断或更可靠的单坐标链标注。

## 方法表述调整

当前方法应表述为“观测图上的时变软关系修正候选”，不应表述为刚体表面保持、物理正确性或已验证的关系增强方法。它仍只针对单条预测的内部结构一致性，不处理整体平移误差、多未来概率或全局事件选择。
