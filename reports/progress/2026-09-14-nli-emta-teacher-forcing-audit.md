## 1. 时间结构与前瞻训练

[Ego4D schema](https://ego4d-data.org/docs/data/annotations-schemas/)给出时间戳 narration 和另外的区间摘要。可以利用时间位置构造观测前缀与未来时段文本的监督配对，并保留未来事件顺序。文字生成不要求每个视频帧对应一个输出词或句子。

这里借鉴 MotionForesight 的任务转换思想；我们仍需把描述训练改为仅从观测视频预测未来文本。时间戳支持样本配对，不自动复制原有网络改造结构。叙述的时间点不等于完整动作的精确起止范围，跨观测截止点的动作需要一致处理，不能直接将相邻 narration 时间戳视为真实动作边界。该限制不妨碍先建立片段级未来文本监督。

## 2. 双向蕴含的来源与用途

[Impossible Distillation，NAACL 2024，3.2 节](https://arxiv.org/html/2305.16635v3#S3.SS2)要求两个方向的蕴含概率分别超过阈值。这与用户提出的以下写法等价：

```text
s_eq(A, B) = min(P_NLI(A => B), P_NLI(B => A))
IsMatch(A, B) = [s_eq(A, B) >= tau]
```

[Semantic Uncertainty，4 节](https://arxiv.org/html/2302.09664v3#S4)也用带上下文的双向蕴含将模型生成回答按含义归组。因此候选与候选、候选与 GT 的双向比较均有方法依据。

借用范围应明确：Impossible Distillation 的语义等价过滤器与其数据集 diversity filter 并不相同，后者还使用单向蕴含关系。此处借用语义等价判定，不默认移植整套过滤流程。

SemDiD 使用嵌入空间的方向引导与排斥；双向蕴含更直接检验两条描述是否相互保留事件内容。[SemDiD](https://arxiv.org/abs/2506.23601)与 NLI 的角色不同。[ModeSeq](https://arxiv.org/html/2411.11911v2#S3.SS6)提供分支分配框架，允许任务相关的 IsMatch；语言 NLI 可以用于该位置，无需同时接入 SemDiD。

### 有效范围

- 在目标指代、时段和描述粒度可比时，同义事件可归为等价；动作增加、对象或顺序改变可以产生非等价候选。
- 等价评分低可能来自事件不同，也可能来自细节省略或 NLI 误判。整句语义差异不自动等于任务所关心的模式差异。
- 例如“喝水后放下杯子”包含“放下杯子”，反向不成立；若短句只省略前半段，则无法仅凭字符串确定两条真实未来不同。明确写成“直接放下”有助于表达预期区别。
- 保留动作、对象、结果和顺序，统一无关指代及描述粒度，有助于让文本等价接近事件模式等价。NLI 在此判断文本关系，不承担视觉合理性认证。
- 分数是 NLI 关系评分，不直接解释为模式概率；在低分区间未必是可靠的事件距离。阈值与事件级判断准确性仍未在新任务上验证。

## 3. 语言版 EMTA 分配

设候选文本为 `N_hat[k]`，GT 为 `N_gt`：

```text
s[k] = s_eq(N_hat[k], N_gt)
G = {k: s[k] >= tau}
k_star = min(G)                 if G is nonempty
         argmax_k s[k]          otherwise
```

有匹配选最早分支，可沿用 ModeSeq。无匹配时取最高等价评分，是用户提出的合理适配选择；它相当于对 `1 - s` 做最近分配，但不意味着获得了经验证的连续语义距离。Impossible Distillation 将低分句对过滤掉，没有证明我们的低分排序用途。该选择可用于训练起点，不把被选中的低分候选标成已经等价或预测正确。

候选间使用同一关系可以统计重复或辅助筛选；EMTA 的正分支分配只要求逐个与 GT 比较，无需强制加入所有候选对的额外损失。

## 4. Teacher Forcing 梯度审核

设模式生成模块参数为 `phi`，文本 decoder 参数为 `theta`。模式条件 `m[k]` 必须由观测输入 `x` 和已有模式条件产生，不向模式生成模块提供真实未来。

候选文本只用于选择 `k_star`。选中后固定该分支条件，并以 GT 的正确文本前缀预测下一个 GT token：

```text
L_gen = -sum_t log p_theta(y_gt[t] | y_gt[<t], x, m[k_star])

dL_gen/dphi = (dL_gen/dm[k_star]) * (dm[k_star]/dphi)
```

该损失可以更新文本生成器及模式模块；NLI、阈值和索引选择不需要可微。每步固定硬分配后优化条件负对数似然，是 WTA 风格的训练适配，不是对整个随机采样与语义评分期望求无偏梯度；实现这一损失不要求 REINFORCE 或穿过离散 token 的直通估计。

例如三个候选分别是直接放杯、喝水后放杯、洗杯，GT 对应喝水后放杯，则选择第二分支。训练时保留第二分支条件，使用真实叙述作正确答案，逐词提高其条件概率。无需把生成候选当作伪 GT，也无需按字符对齐候选与真值。

### 实现必须满足的条件

1. `m[k]` 以可微连续条件接入文本生成器，例如 soft prefix 或 cross-attention；不能只用不参与计算的分支编号代替。
2. 采样和 NLI 可以不保留梯度，但训练前向要保留或重建 `m[k_star]` 的计算图。缓存已 detach 的模式向量后直接计算文本损失，无法训练其上游模块。重算应保留选择时的分支条件，不能改用 GT 填充模式历史。
3. 主干冻结只限制哪些参数更新，不应将需要对输入求导的 decoder 前向全部放入 `no_grad`。可只训练 adapter 与模式模块；[Prefix-Tuning](https://aclanthology.org/2021.acl-long.353/)为通过冻结 LM 训练连续条件提供相关先例，但不直接验证本项目的动态模式条件。
4. 只有选中分支接受直接 GT 文本损失；共享参数及前序模式可能经记忆依赖间接收到梯度。置信度另按 ModeSeq 分配标签训练。

## 5. 成立结论与效果边界

- 用户提供的训练推导在上述条件下成立，已经给出“文本损失如何训练到生成器”的实现路径；该事项不再是原理上的未解决障碍。
- 一条分支的随机候选会影响硬分配，可能使标签随采样波动，这是需要观察的训练噪声；不据此否定该方法或强制更换训练范式。
- 梯度可达不证明生成器有效利用不同模式条件。若条件被忽略，各分支仍可能相似；这可通过条件替换的输出敏感性和梯度检查直接判断。暂不因这一可能性预先增加额外合理性模块。
- 当前没有充分依据用更复杂的训练方法替换主体方案。双向 NLI、EMTA 式分配与条件 teacher forcing 可以作为具体待验证版本；监督粒度与 NLI 的任务适用性仍需检查。
- 第一阶段仍限于未来文本与模式，未增加轨迹解码评价要求。
