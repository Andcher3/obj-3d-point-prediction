## 误差推导（数学条件，无经验性能宣称）

真实点与参考点为 X_i、c；估计误差为 epsilon_i、epsilon_c。

`(Xhat_i-chat)-(X_i-c) = epsilon_i-epsilon_c`。

点对关系误差为 `epsilon_i-epsilon_j`。

精确均方误差为 `E||epsilon_i-epsilon_c||² = E||epsilon_i||² + E||epsilon_c||² - 2 E[epsilon_i·epsilon_c]`。因此需要比较参考点误差及误差相关性，不能只比较输出维数。

示例：各 query 的三维均方根位置误差均为3cm，零均值且相互独立，点对向量均方根误差为sqrt(18)=4.24cm；参考点误差1cm且与 query 独立时，相对参考点向量误差为sqrt(10)=3.16cm。该例仅演示条件成立时的改善，不是实验预测。

反例：两 query 都有完全相同的3cm共同偏移，点对向量误差为零；改为相对于无误差的外部参考点，相对向量保留3cm偏移。同一个三维估计中的误差抵消可能比独立模型参考更有效。

若参考点仅由原 query 的均值得到，则 `r_i-r_j=(X_i-c)-(X_j-c)=X_i-X_j`，没有获得独立几何证据。参数化、损失和学习难度可以改变，但不会自动修复原始伪标签。

参考点准确不会消除 query 的身份错配、局部深度畸变或表面点漂移。标量距离可能对方向误差不敏感，但只限制到参考点的半径；不限制球面上的方向，无法独立确定旋转或点间排列。

## 跟踪与预测的训练角色

- 仅观测历史预测出的未来参考轨迹仍是预测；可作为额外条件或蒸馏来源，质量需要独立验证。
- 以完整真实视频恢复各帧参考点/物体位姿，才是在构造未来运动的伪监督；该恢复流程同样有几何与跟踪误差。
- 共同表示候选 `X_i(t)=c(t)+r_i(t)` 保留所有点的未来三维输出；r_i 可以随时间变化，允许旋转、关节运动和形变。仅借用物体级位置不要求所有目标采用刚体模型。
- 参考点三维位置、query 位置及时间网格需可比较。新的中心模型若使用独立几何链，同样可能引入坐标与尺度差异。

## 文献核查
