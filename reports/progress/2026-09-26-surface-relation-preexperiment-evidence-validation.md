# 实验前点间关系方法的证据核对

- 日期：2026-09-26
- 范围：只核对实验前已经提出的方法假设与设计依据；未运行新实验
- 核验状态：ANALYZED

## 得到支持的部分

1. 图上的边关系可以被整合成统一的节点坐标修正。E0 在单/多连通分量、完美关系、零修正、节点置换和梯度检查中通过；说明 constrained-L2 与组件级 gauge 的数学接口成立。
2. 现有点轨迹中确实存在可由相对关系恢复的内部结构误差。E1 的 baseline 有非零 relative-vector error，oracle relation 使可恢复 RVE 达到 100%；这支持“点级预测可能产生内部结构漂移，关系修正具有可定义目标”。
3. 投影方法对小到中等边噪声具有一定容错。E1 在 5% Gaussian edge noise 下宏平均恢复约 75.1%，且没有共同平移漂移；它只支持受控、较干净关系下的可用性。
4. 组件级零空间处理是必要且可实现的。E0 的多分量测试满足各组件 gauge；这验证了解的唯一化方式，不验证真实图一定连通。
5. 关系模块可以接入 MotionForesight 的 query 输出接口。E3 前置审计在五个视频上得到有限的 `P0,H`、正确未来槽位和无未来 RGB 输入；受控 head 测试进一步通过 constrained-L2、反传、单样本拟合和同步 query permutation。
6. 观测期图构造在当前样本上具有工程可用性。E2-G 的 2D `k=3` 图五个视频均连通、无 bridge；32→48 及 48→64 的密度比较未见系统性 RVE 增加。它支持稳定候选，不能证明语义邻接正确或模型收益。

## 尚未被证实的核心部分

- Relation Head 能否从真实 `H` 学到超出 baseline 或 node residual 的关系修正；
- 关系修正能否改善真实 MotionForesight 的未来轨迹和长期散开；
- 2D/3D 图边是否对应真实物体表面关系；
- 同一关系目标能否覆盖 rigid、articulated、deformable 三类运动；
- 关系损失、图积分和最终坐标预测的联合训练是否有效。

## 证据边界

E0 是数学/实现验证，E1 是三条底层视频上的 oracle 与噪声验证，E2 是五视频上的图工程检查，E3 是接口与受控优化检查。真实视频监督因三维标签登记失败而未放行，因此不能把任何上述结果表述为完整方法的预测收益。
