# 正式单上下文关系目标闸门复核

- 日期：2026-09-24
- 状态：浇水壶正式 16 帧质量闸门失败；真实视频训练继续暂停

## 复核结果

- 修正后的脚本已经根据 `timestamps_s` 和 `t0_seconds` 确定 t0，并要求 16 帧窗口的 t0 索引为 6、未来切片为 `7:16`。
- 浇水壶正式窗口满足 16 帧协议、48/48 有效 query 和 2D 图连通，但实际 t0 anchor p90 为 `5.27%`、最大值为 `29.91%`，4/48 query 超过 10%。
- 正式未来两两距离漂移 p90 为 `78.63%`，当前结果不能视为可靠的刚体关系监督。
- 其余四个视频只有 12 帧输出，不能由旧结果推断正式 16 帧质量。

## 决策

- 不生成真实视频 Relation Head 训练缓存。
- 可将其余四个视频的 16 帧 dense 输出作为一次有界的最终数据审计，用于判断问题是否具有对象依赖性；不能据此临时修改闸门或挑选有利样本。
- 在五视频正式 16 帧审计完成前，只运行合成、oracle 和 E1 受控目标的接口、梯度及 constrained-L2 integration probe。
- 即使部分视频通过单上下文质量闸门，还必须解决其与 observed-only MotionForesight `P0,H` 的监督接口，不能直接开始正式训练。

## 方法假设状态

- “同一物体点之间存在时变相关运动”仍是可保留的研究假设。
- “关系目标由当前 TrackCraft3R/DA3 pseudo-GT 可靠提供”尚未成立。
- “点间距离近似保持不变”不成立，必须继续采用软的时变关系表述。
