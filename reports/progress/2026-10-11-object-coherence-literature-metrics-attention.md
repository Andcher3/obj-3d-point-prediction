## 1. 已发现的主要重合

| 工作 | 已核查的方法事实 | 与本研究重合及区别 |
| --- | --- | --- |
| [CoTracker](https://co-tracker.github.io/) | Transformer 联合处理多个查询点，利用运动相关性 | 点间共享已有明确先例；任务为输入视频内的跟踪 |
| [SpatialTracker](https://arxiv.org/html/2404.04319v1)，§3.3 | 跨点 Transformer，加学习得到的同刚性部件权重，直接约束点对距离随时间保持 | 关系约束改善三维空间一致性已有先例；输入含待跟踪帧，局部刚性也有专门建模 |
| [Generative Point Tracking and Forecasting](https://gen-points.github.io/)，官方架构说明 | 每个块包括同一点跨时间注意力、同一帧所有点间注意力、点与图像特征的注意力 | 未来点预测中的联合注意力已有先例；仅增加普通点间注意力创新性弱 |
| [TrajLoom](https://arxiv.org/html/2603.22606v1)，§3.2.1 | 从观测轨迹和视频预测未来二维轨迹；VAE 重建同时匹配时间速度及多尺度邻点相对运动 | 未来轨迹生成中的局部协调、邻点关系监督已有直接先例；其约束主要用于二维轨迹 VAE 的表示学习 |
| [Visual Grounding of Learned Physical Models](https://proceedings.mlr.press/v119/li20j/li20j.pdf)，§3.3 | 粒子图传递信息；刚体粒子共用物体中心平移和旋转，非刚体采用不同更新方式 | 物体级共享运动加局部点运动的思想已有先例；研究环境及表示、模型先验与本项目不同 |
| [ObjectForesight](https://objectforesight.github.io/)，模型架构 | 物体中心化几何条件，预测刚体物体未来六自由度位姿 | 共享物体运动具有相关预测先例；输出对象位姿，未覆盖本任务要求的任意关节/形变点轨迹 |

历史参考：[SE3-Nets](https://rse-lab.cs.washington.edu/projects/se3-nets-learning-rigid-body-motion-using-deep-neural-networks/) 也以共享刚体变换生成点运动。本项目已有详细核查见 `2026-10-08-reference-point-constraint-literature.md`。

因此，“让点共享信息”“同物体点共同运动”“点对几何辅助监督”都不能单独作为原创主张。可继续研究的具体问题是：在视频未来三维点预测中，怎样利用目标对象的共同运动和允许变化的局部关系，在普通联合注意力之上减少可测量的结构错误。机制差异、适用范围和性能均待建立，不能仅凭换成三维或冻结骨干声明创新。

这些是潜在空间格点之间的信息交换，不能直接称为每个稀疏 query 对应一个注意力 token。[论文附录 A.1](https://arxiv.org/html/2607.16192v1) 确认使用视频 DiT、在自注意力投影上训练未来 LoRA；主要监督是解码坐标 MSE。

结论：基线具备跨时间、跨位置的信息共享通路；没有显式物体关系目标不等于它没学到物体关系。源码通路存在也不证明信息已经被充分利用。

本项目 G1 中双方还共用物体级特征，比较的是额外局部邻点历史。因此 ADE 增益 2.47%、关系向量/长度误差改善 8.14%/10.81%支持新增关系信息可被利用，不能证明通用注意力缺乏跨点能力。此前尚无等输入、等容量普通点注意力与专门关系结构的直接对照。

## 3. 衡量点集散开：建议的精简指标

现有 `scripts/run_cross_point_probe.py:15` 已计算全部无序点对的三维向量与长度误差，应复用而非重命名成新指标。新增必要部分是尺度归一化、少数异常点诊断和随预测时间的曲线。

记预测点为 p_i(t)，对应真值为 g_i(t)。所有方法使用同一 query 身份、真值有效性集合及时间槽。尺度 s 固定为 t0 真值对象三维包围盒对角线，仅用于评价；不按预测输出或未来帧重新拟合尺度。

### 3.1 归一化点对长度误差（主结构指标）

令 d_hat_ij(t)=||p_i(t)-p_j(t)||，d_gt_ij(t)=||g_i(t)-g_j(t)||。

`E_shape(t) = mean_(i<j) |d_hat_ij(t)-d_gt_ij(t)| / s`。

含义：预测中各点的相互间距与真实物体同一时刻的间距差多少。整体正确平移或旋转不改变此指标；错误膨胀、收缩、局部散开会增加误差。真实关节运动或形变以未来真值为参照，不要求距 t0 保持不变。

### 3.2 异常点结构误差（捕捉少量点飞离）

`a_i(t)=mean_(j!=i) |d_hat_ij(t)-d_gt_ij(t)| / s`。

报告 a_i 最大的 `ceil(0.05*N_valid)` 个点的平均值。48 点时为最差 3 点。这样单个飞离点不被全部 1128 个点对的均值过度稀释；同时保留每点误差的可视化。

这是一项拟议诊断，不宣称已有标准命名。比例固定在测试前；仅凭尾部下降不放行方法。

### 3.3 时间与轨迹准确性

- 保留点对向量误差，衡量相对方向和长度；它与仅长度指标互补，但会响应整体朝向预测错误。
- 对所有未来时刻绘制 E_shape(t)，并报告早、中、晚三段，判断是否随预测时域恶化。
- 同时报 ADE/FDE（平均/最后时刻位置误差）。结构更协调但整体运动错，不能称为预测成功；停止运动或把点集压缩也要受到对应真值指标惩罚。
- 额外比较两两长度的有符号偏差可解释膨胀或收缩方向，只作诊断，不能用正负抵消后的均值代替绝对误差。
- 对确定为刚体的测试子集，可附不允许缩放的最佳旋转/平移拟合残差，量化非刚性破坏；不得据此给全部目标加入硬刚体前提。

[What Happens Next?](https://arxiv.org/html/2509.21592v2)，§3.4，使用 LRTL（轨迹矩阵的低秩重建误差）衡量二维刚性协调，也明确指出静止预测可取得低 LRTL。其 rank-5 规则不能直接移植为本项目所有三维目标的主指标。

指标实现前应验证六类受控输入的响应：整体平移、整体旋转、单点飞离、整体收缩、符合真值的真实形变、点身份交换。这是待做的 CPU 数学检查，本轮未执行。

## 4. 怎样检验专门结构的价值

应检验具体结构在有限训练资源下是否有额外收益；不把普通 Transformer 无法表达点关系当作前提。

### 匹配对照

| 组 | 作用 |
| --- | --- |
| 原始 MotionForesight | 不添加模块的实际基准 |
| 等规模逐点修正器 | 衡量一般校正和新增参数的收益；共同物体特征的有无必须明列 |
| 普通点 Transformer | 同一物体的所有 query 联合 self-attention；作为真正的通用信息共享对照 |
| 专门共享结构 | 与普通点 Transformer 共用输入，只改变物体共同运动/局部关系的处理机制 |

普通与专门结构必须使用相同 RGB/历史/几何/latent 条件、坐标和 query 规则、预测接口、参数预算、训练数据及调参次数。显式关系输入也应给予普通结构，才能区分“多了信息”和“交换方式更好”。提供坐标/时间编码，不能故意削弱普通注意力基线。

在普通与专门结构上各做“仅坐标损失”和“坐标＋直接输出关系损失”，形成 2×2 对照。关系损失由实际预测坐标导出点对关系；此前 G2-L 使用独立辅助距离分支，不能代替这一对照。

模块比较保持相同插入位置与冻结策略。若研究主张涉及预训练 Transformer 的适配能力，另需等训练参数预算的原骨干适配对照；输出端胜出只能支持输出端读出/共享方案，不足以宣布骨干不能利用关系。

### 机制证据

若专门结构确实胜出，再移除其共同运动或局部关系组件，检查对应结构收益是否消失；使用同一物体随机邻接诊断，区分普通信息池化与特定邻接的贡献。可对同一冻结输入只扰动少量 query 的观测特征，比较两个模块的异常传播及其他点稳定性，不重新运行 DA3 或改动真值。

注意力图可用于解释，不能单独证明通信有效。刚体上的简单刚体投影也可作结构误差诊断，防止把简单几何投影能取得的结果归因于复杂网络。

### 事前决策

1. 普通注意力已达到相同结构/位置收益：采用更简单的机制，停止以特殊共享结构作为核心贡献。
2. 专门结构在等输入、等预算下同时减少结构误差并保持位置预测质量，关键组件移除后收益消失：支持该设计中的结构偏置（让模型更容易学习某类关系的设计倾向）具有价值。
3. 只有直接关系损失有效：贡献转向监督目标，不能归因于新通信架构。
4. 两种共享方案都没有收益：停止当前新增模块方向，保留并报告已完成的 G1 信息增量结果。

具体实用增益阈值和允许的 ADE 变化须在新实验前固定，不能重写 G1 已用的 5% ADE 判据。现有 40 测试场景已反复用于探索，后续确认性比较应使用新留出的独立场景；该要求不等于泛称已有结果毫无价值。

## 5. 当前研究判断

已有文献充分支持“点关系可以帮助协调运动”这一研究依据，也使宽泛观点缺乏独立创新性。当前最值得验证的是特定共同运动与局部关系机制的增量作用，以及它是否真正减少点集结构错误。先完成指标和普通注意力匹配对照的协议，再决定是否提出专门架构。本轮完成研究审查，未选择新架构、未更改已完成实验结果。
