## 坐标问题与用户批准的处理

- 首场景 DA3 query 深度中位数约 0.304，GT 约 6.201，逐点深度尺度比约 18.8–24.3，不能将两个数组直接作为相同单位的坐标。
- 仅观测的 DA3 帧 0 query 几何到 GT 帧 0（均表达在观测相机 6）相似变换拟合尺度 23.70；四折留出 p90 残差约 0.862、占 GT 物体 RMS 半径 1.268。该残差说明几何估计误差很大，未称为几何质量通过。
- 用户明确批准：以观测期 GT 定义旋转、平移、尺度，固定应用到未来标签与所有组的评价；不引入任何未来信息到拟合。
- 实现：从 DA3 帧 0 的 48 个 query 几何与同身份 GT 帧 0 拟合一个全局相似变换。未来 GT 标签逆变换到模型估计坐标域；原始输入、原始预测、全部特征数组均保持原样。输出评价时欧氏误差统一乘回拟合尺度，两组完全共用。
- 标定既不逐点平移也不强制零残差，不消除 DA3 非刚性的形状误差；结果属于 **GT 辅助的观测坐标标定评价**，不等同于无 GT 标定的绝对尺度 RGB-only 部署精度。

## 40 个独立测试场景结果

所有误差越低越好，按场景平均，单位为标定后的模拟器坐标单位。线性预测器采用 ridge（带参数惩罚的线性回归），两个输入条件均由验证集选中 alpha=100；神经网络为两层 128 宽 MLP（小型全连接网络），两组均为 122,413 参数。

| 指标 | 原始 MotionForesight | 线性：屏蔽邻点 | 线性：真实邻点 | 邻点相对屏蔽条件改善 |
| --- | ---: | ---: | ---: | ---: |
| ADE（未来所有点、所有时刻的平均位置误差，主指标） | 3.54882 | 3.44565 | 3.36060 | 2.47% |
| FDE（最后预测时刻的位置误差） | 3.99138 | 3.99351 | 3.96516 | 0.71% |
| 点间三维向量误差 | 1.17751 | 1.14099 | 1.04811 | 8.14% |
| 点间长度误差 | 0.62830 | 0.60559 | 0.54013 | 10.81% |
| 未来位移变化误差 | 1.81783 | 1.69141 | 1.66982 | 1.28% |

- ADE 邻点增益的 95% 配对场景区间为 0.58%–4.13%；针对两个预测器比较的 97.5% 区间为 **0.35%–4.35%**。上限低于事前 5% 实用增益门槛，本次线性读取方案未达到该门槛。
- ADE 改善发生于 21/40 场景；点间向量误差改善发生于 35/40 场景。均值改善不能推导为每个场景或每个 query 均改善。
- 向量误差改善的描述性 95% 区间为 5.66%–10.41%，长度为 5.47%–15.60%。这些是次指标，不作为重新选择主指标或放行门槛的依据。
- FDE 改善的描述性 95% 区间为 −0.30%–1.64%；未来位移变化为 −0.15%–2.52%，二者均包含零，尚无明确动态收益证据。
- 真实邻点线性预测器相对原始 MotionForesight 的 ADE 改善为 5.30%。其中同时包含训练修正器的影响；信息增量的匹配比较仍为真实邻点对屏蔽邻点的 **2.47%**，不能用 5.30% 替代事前判据。

### 神经网络训练情况

六次训练均实际执行 20 个 epoch（完整遍历训练点一次称一个 epoch）；训练归一化平方误差从约 10.16–10.43 降至 0.32–0.37，但验证 ADE 从初始化的约 3.32 上升，最后一轮约 6.13–6.49。验证集最终均选中 epoch=-1，即尚未训练的零修正初始化。

因此六个被选中的最终模型均与 baseline 相同，ADE=3.54882。记录中的零差异/零区间只描述这六个相同输出的比较；不能据此认定邻点信息价值精确为零。可判断该固定神经网络及其训练流程未学到可推广的修正，训练拟合与验证恶化同时出现，符合过拟合表现；具体成因尚未单独隔离。

### 当前方法判断

1. 当前估计观测条件下，邻点历史对简单线性预测器存在有限的增量价值，尤其体现在点间相对几何。此结果支持继续把“关系信息可能有用”保留为假设。
2. 事前 5% 主指标门槛未达到；尚不能证明当前方法具有足够实用收益、已经改善运动动态，或已经验证表面距离监督。
3. 小型神经网络结果不足以否定所有交换信息的结构。当前输入已含物体级共同特征、冻结模型已有跨点处理；本实验检验的是新增局部邻点历史的增量价值，不能称为完全有/无点间信息的比较。
4. 标签来自模拟器真实轨迹，没有教师伪标签。DA3 几何与冻结模型的估计误差仍在输入中；全局坐标标定只处理单位和坐标关系。首样本较大形状残差不因标定而消失。
5. 结论限于当前 MOVi-F 筛选目标、观测时域、特征和两个预测器。测试结果没有用于追加参数搜索、过滤样本、替换指标或修改阈值。
