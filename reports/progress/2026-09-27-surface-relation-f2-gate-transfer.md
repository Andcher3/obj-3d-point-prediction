# F2 保守门控与逐点修正对照实验

- 日期：2026-09-27
- 状态：`COMPLETED_EXPLORATORY_CROSS_RESOLUTION`；预定的跨样本放行判据未通过。
- Material Passport：`academic-research-suite / experiment-agent`；结果完成，独立复跑验证为 `VERIFIED`（仅验证计算可复现，不验证标签真实性）。

## 问题与固定协议

检验现有冻结 MotionForesight、输出端三维边关系头能否靠仅使用观测和 baseline 输出的保守门控改善未参与训练的视频，并与参数规模接近的逐点修正头对照。

开发集固定为四段 Ego4D 既有 F2 视频，48 query、7 帧观测、未来 9 槽位。沿用 history 边头与锚定未来位移监督；训练槽位 `0:7`，开发视频验证槽位 `7:9`，5 种子、400 步、学习率 `0.01`。逐点对照使用同一 H、观测点历史和 baseline 未来坐标，输出零质心修正；边头 1571 参数，逐点头 1587 参数。二者都使用相同去质心/三维边向量等权训练目标，冻结 baseline。

预先固定三种修正幅度：`g=0` baseline、`g=0.25`、观测分数高于四开发视频中位数时取 `g=0.25` 否则 `g=0`。观测分数是 baseline 未来三维边向量与最后观测帧边向量的平均差（以观测物体尺寸归一化）；开发视频中位阈值 `0.03192`。两类头使用完全相同的门控。门控先写入 [冻结协议](../../configs/surface_relation_f2_gate_transfer_2026-09-27.json)，模型和阈值写入 `frozen_before_transfer.json` 后才由程序加载转移视频标签。

转移集是两段 PointOdyssey：`r4_new_f` 和 `scene_d78_0318_3rd`。远端按现有 TrackCraft3R query-only 路径仅对前 7 帧推理，获得 `(7,48,3)` 观测轨迹；首次调用缺 tokenizer 环境变量而在模型加载前退出，按项目既有运行配置补齐后两段都正常完成。48 个 query 与既有 22 帧标签运行完全同序，最大 query 坐标差 `0 px`，伪标签逐点以新观测轨迹 t0 锚定；未来视频输出仅用于训练目标/测试标签，从未作为关系头的显式输入。

## 结果

表中三项依次为原始 ADE（米）、去质心点误差、三维边向量误差（后二者按物体尺度归一化）；head 数值为五种子的**逐指标中位数**。两段转移视频的观测分数为 `0.06012`、`0.04000`，都高于阈值，因此可拒绝门控均选 `g=0.25`，与固定幅度完全相同。

| 转移视频 | baseline | 边头 `g=0.25` | 逐点头 `g=0.25` |
|---|---|---|---|
| `r4_new_f` | `.07472 / .05123 / .06329` | `.08086 / .05477 / .06473` | `.07272 / .05029 / .06215` |
| `scene_d78_0318_3rd` | `.02758 / .05946 / .04166` | `.02659 / .04827 / .03661` | `.02667 / .05132 / .03767` |

在 `r4_new_f` 上，边头比 baseline 的 ADE、去质心误差、边向量误差分别高 `8.2%/6.9%/2.3%`，5 个种子中有 4 个 ADE 恶化超过预定 `5%` 安全界限；逐点头中位数三项小幅改善。在 `scene_d78_0318_3rd` 上，边头和逐点头均改善，边头去质心/边向量分别降低 `18.8%/12.1%`，逐点头分别降低 `13.7%/9.6%`。边关系并未在两段上稳定优于逐点对照。

开发集历史的留出预测中，门控在四视频分别取 `0.25/0.25/0/0`，避开两段低观测变化视频的过修正；转移集却两段都选择修正。因此该观测变化分数未能可靠识别 `r4_new_f` 的失败情形。按冻结协议要求“两段视频均改善两项结构指标、ADE 不恶化超过 5%”，结果为 **FAIL**。

同一命令在另一输出目录确定性复跑，两份 `results.json` 的 SHA-256 完全相同。脚本编译通过；测试集中没有参与模型参数、训练数据归一化、checkpoint 或门控阈值选择。

## 可解释范围与限制

这次实验证伪的是**当前固定 0.25 加观测边变化阈值的简易门控能够稳定改善这两段转移视频**。不能据此否定所有关系建模，亦不能宣称逐点方案已在正式测试集胜出。只有两段视频、同五个随机种子不构成十个独立样本；两个目标此前已用于其他方法分析，不是全新盲测样本。转移集与训练集分别使用 `process_res=392/518`，特征分布不同。尤其转移集沿用了完整 22 帧上下文重建的 DA3 输入，MotionForesight 和观测期 TrackCraft3R 所读几何可能间接包含未来上下文；它不是严格的观测 RGB-only 推理测试。未来监督也是 TrackCraft3R 伪标签，非可信三维真值。以上因素使本次对**冻结输出端接口整体**的取舍保持未定。

没有进行显著性检验。统计解释 11/11 类常见风险均作检查：主要风险为视频级样本少、既往探索、选样与跨分辨率、未来上下文混入和伪标签；应按视频而非按点/种子报告，不把方法比较解释为接口的因果证明。

## 决策与输出

拒绝把这一规则作为可用门控；不再用这两个转移视频反复调阈值或重选系数。当前允许保留冻结输出端接口为待验证候选；要做正式接口取舍，必须使用新的、先锁定的独立视频，统一观测期 DA3/TrackCraft3R 处理分辨率，并采用可核验的评价轨迹。若在该条件下仍不能稳定改善 baseline 且不优于逐点修正，再考虑将点间关系引入生成过程。
