# 当前两阶段方法的独立学术审核

日期：2026-09-20

## 总体判断

当前方法作为“高层未来 narration 分支是否能控制指定物体的稠密三维未来”的研究版本具有逻辑连贯性。它把观察视频中的事件理解与三维几何预测分开，第一阶段输出可解释的未来语义，第二阶段保留 MotionForesight 的稠密点轨迹接口。当前版本仍属于语义条件接口验证，不能单独支持连续轨迹分布、同一 narration 内的运动随机性或校准概率等更强主张。

## 主要薄弱假设

1. narration 是否是稳定的模式变量：自然语言会省略几何、接触和时间信息，也会因为描述粒度产生差异。它是未来的描述，不是独立的意图因果变量。需要统一对象、时间窗和事件粒度。
2. ModeSeq 迁移是否保持原假设：原方法的连续 mode embedding 直接经过轨迹和置信度 head，前序 embedding 是替代轨迹模式的 memory。若改为原始 narration token，模型可能把前一条候选理解为已发生的动作并继续续写。原始 token memory 属于文本任务的扩展，不是 ModeSeq 机制本身的等价复制。
3. 双向蕴含的低分含义不足：`min(P(A=>B), P(B=>A))` 可以判断候选与 GT 是否近似等价；低分同时包含合理的不同事件、互斥事件、对象错误、无关文本和幻觉。EMTA 的负标签只能表示“没有匹配当前 GT”，不能表示“未来不合理”。
4. 单一 GT 的监督边界：ModeSeq 可以用单一 GT 选择一个正分支并训练置信度，因此训练可行；单一 GT 无法给未发生候选提供正例，也无法由此得到替代未来概率。
5. token sampling 的语义产物：多个文本可能只是同义改写，也可能发生动作顺序、对象或结果变化。采样次数本身不能代表模式覆盖。
6. 文本条件可能被视频捷径压制：已有文本条件轨迹 probe 表明文本会改变输出，但视觉历史仍可能主导宏观方向。恢复文本 cross-attention 和加入 LoRA 后仍需实测。
7. 级联训练分布：用真实 narration 训练第二阶段、推理时使用第一阶段生成 narration，会产生输入分布差异；直接用预测 narration 训练又会引入第一阶段错误和匹配偏差。正式协议必须固定并报告 oracle 与 predicted 的差距。
8. 时间和目标对齐：Ego4D narration 的时间戳不等于精确动作边界，文本可能描述人或其他物体。若 narration、目标 mask 和三维伪标签不属于同一未来窗口，模型会学到错误条件关系。
9. 学术贡献强度：MotionForesight、ModeSeq、NLI 和 Wan 文本通路各自已有来源。论文贡献需要落在可测的新现象上，例如固定候选预算下事件重复减少、GT 覆盖提高，并且语义分支能够改变目标物体的宏观三维未来。

## 可以保留的设计判断

- 单一 narration 监督不构成方法上的阻断点，ModeSeq 式 EMTA 可以提供稀疏分支分配。
- 基础版本不需要另造 narration 语义摘要；严格迁移 ModeSeq 时使用连续分支状态即可。
- 第一阶段暂不做轨迹解码评价是合理的范围划分。
- 第二阶段暂时采用确定性输出有助于先验证语义到几何的条件接口。

## 快速验证顺序

### 第一组：数据和语义匹配

1. 抽取约 100 个样本，人工检查目标是否一致、narration 是否落在统一未来窗口、动作粒度是否可比、三维伪标签是否有效。
2. 构造同义、动作顺序变化、对象变化、单向包含、互斥、无关和粒度变化句对，人工标注事件等价。用双向蕴含分数测 AUROC/F1，确定 `tau`，同时记录典型误判。

### 第二组：第一阶段多分支

3. 固定视频、目标和候选预算，比较独立 token sampling、ModeSeq 式连续状态 memory、去掉 memory 和打乱 memory。记录目标相关率、人工合理率、NLI 聚类后的 unique mode 数、重复率、GT match@S 和 oracle@S。
4. 做分支顺序置换和前序 memory 清空测试。若输出不变，后续分支没有使用 memory；若输出变成“上一候选之后继续发生的动作”，替代未来边界需要重新设计。
5. 比较同义改写、动作顺序改变和对象改变的输出。理想表现是同义改写近似合并，顺序和对象改变产生事件级变化。

### 第三组：第二阶段文本接口

6. 在极小数据集上用同一视觉输入配对两个明确文本和两个合成轨迹，训练 cross-attention LoRA 过拟合。检查文本 context 梯度、文本替换后的输出变化和训练目标复现。
7. 在真实小子集比较无文本、正确文本、空文本、随机置换文本和冲突文本。报告 ADE/FDE、端点误差、可见点比例、局部连续性，以及文本替换造成的宏观位移变化。
8. 分别输入 GT narration、第一阶段候选中与 GT 匹配的 narration、top-1 narration、oracle 候选和空文本，测量阶段接口损失。
9. 比较 GT narration 训练、匹配预测 narration 训练和混合训练，确定级联协议。

## 继续研究的判据

- 顺序 memory 相比独立采样降低重复率，且不损害目标相关性和 GT match@S。
- 正确文本优于空文本和置换文本；同义文本产生近似轨迹；事件改变主要影响宏观终点或方向，同时保持历史边界和局部几何。
- 预测 narration 与 GT narration 的性能差距可测且可解释。

若这些条件不成立，应先修正数据、语义匹配或文本通路，再加入更复杂的概率生成和模式内随机性。
