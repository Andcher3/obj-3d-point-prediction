# 点间关系方案的结构性调整判断

- 日期：2026-09-27
- 完成工作：复核原方法记录、F2 四视频留出及最新保守门控跨视频诊断，评估是否继续优化门控或调整模型接口；未修改模型、未启动训练。

## 已有证据

- E0/E1 oracle 和噪声边实验验证：在给定有用的边修正时，受约束图积分能将其整合为点位置；这没有证明边修正可由观测稳定预测。
- F2 的 `anchored_displacement` 已消去同一 query 的两次 TrackCraft3R t0 静态差异；history/shared/safe 在四视频留出中都只有 1/4 同时改善两项结构指标。后验最佳缩放一般小于 1，且方向信息有限。
- 保守门控与逐点对照在两段 PointOdyssey 转移视频上只有一段使边头的去质心及三维边向量误差改善，另一段的绝对轨迹、去质心和边误差都变差；逐点对照两段均小幅改善。两段转移数据采用 `process_res=392`，开发集为 518，且转移集的 DA3 由完整 22 帧重建，不能作为严格仅观测输入或正式泛化证据。

## 判断

有理由对关系子方法作**结构性重设计**。当前逐边独立预测相对 baseline 的三维修正、随后一次图积分再由门控选择强度，主要限制是修正方向及跨视频稳定性；积分与后验门控不会自行提供缺失的未来运动信息。不能据此判定“点间关系无价值”或“冻结特征必然不能使用”。

保留目标为指定物体的未来三维点轨迹，保留仅由观测帧建立的 query 图和软相对运动约束。优先候选是**查询点对齐的联合时空关系解码器**：每个点读取预测表示、观测三维位置/运动及物体共享信息，点之间通过稀疏消息交换，联合产生未来坐标；以轨迹误差和未来相对位置误差训练。真实转动、关节运动与形变允许改变边长，不加入固定刚体约束。训练时需要可靠、同一 query 的观测—未来坐标监督；未来帧只用于离线标签。

撤出主方法的有独立整视频幅度门控、观察边变化阈值、依赖事后测试标签确定强度的方案，以及把图积分作为所有关系信息进入轨迹的唯一通道。图积分保留为对照和几何诊断；可靠性权重只在证实标签/边质量不足时处理输入或损失，不充当预言 baseline 错误的门控。

比较时固定数据、样本和训练预算：MotionForesight 原始输出、等参数逐点解码器、相同架构但有/无跨点消息的关系解码器。首先冻结视觉先验、训练 query-level 解码器以隔离关系通路；若监督可靠且均未改进，再单独比较轻量可训练生成期 adapter。不能在不可信的跨分辨率、未来上下文输入上裁决该接口。正式检验需要全新独立视频、观测期单独生成的输入和可核验的未来标签。

## 结果边界与下一步

这是方法候选与实验区分，不是已验证的新架构；这次判断只针对点间关系子方法，不修改项目更广泛的多未来概率目标。下一步先确定可训练的同坐标、仅观测输入数据及盲测集，再开展等容量联合关系解码消融，预先固定以视频为单位的结构与绝对轨迹指标。
