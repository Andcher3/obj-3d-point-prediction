# 第二阶段视觉模态削弱与文本条件评估

日期：2026-09-16

## 结论

在第二阶段训练中对视觉输入做随机 mask 具有方法依据，可作为视觉模态 dropout、文本条件敏感性诊断和训练正则化。但“对历史视频或所有图像信息大量随机 mask”不宜直接作为正式方案：文本通常不能提供目标点的精确位置、姿态、尺度、深度、相机运动和短时速度，过度遮挡会提高文本变化对输出的影响，同时损害三维轨迹精度和局部物理连续性。

TrajLoom 当前只测试了两个视频。固定随机种子改变文本时轨迹会改变，但两个视频中的文本条件都保持原视频主导的运动方向，冲突文本没有造成方向反转。因此现有证据支持“文本通路有效但受视觉约束”，不能概括为所有模型普遍依赖视频，也不能把增加文本效应等同于获得可靠文本控制。

## 推荐的视觉削弱范围

```text
高层场景/外观 token       可较强 mask
目标 mask、query/history  保留
pointmap/局部几何         保留或轻度 mask
最近几帧局部运动           保留或轻度 mask
```

优先削弱非目标区域、较早的长程场景帧和 RGB 场景 token；不要第一轮同时丢弃目标点历史、目标 mask、全部 pointmap 或整个视觉编码结果。future mask latent 表示未知未来槽，不等同于历史视觉证据，不应仅靠给它加噪来制造文本依赖。

## 训练形式

使用固定形状的 learned mask token 或显式二值 mask embedding，保留时空位置。训练样本混合完整视觉和部分 mask 输入：

```text
L = L_full + lambda_mask * L_mask
```

完整视觉分支用于保留 MotionForesight 的几何和物理能力，mask 分支用于提高文本在高层事件上的作用。mask 只作为辅助策略，不能替代 Wan T5 cross-attention LoRA。训练时大量 mask、推理时始终使用完整视频会产生分布差异，因此不能采用 mask-only 训练作为正式模型。

## 最小实验矩阵

1. 完整视觉 + 正确 narration：文本条件基线。
2. 完整视觉 + 空/置换 narration：测量文本贡献。
3. 目标与历史保留、非目标 RGB mask + 正确 narration：测量文本补偿。
4. 同上 + 冲突 narration：测量真实文本敏感性。
5. RGB 场景 token 与 pointmap 分别逐级 mask：分离外观捷径和几何信息的作用。
6. 保留最近帧、加大早期帧 mask：检查长程视觉与局部物理的分工。

同时报告 ADE/FDE、端点误差、可见点比例、局部连续性、文本替换前后宏观轨迹差异和 mask 前后的精度变化。若文本敏感性上升但真实 narration 的精度或物理连续性明显下降，说明模型只是失去视觉约束，不应将该 mask 强度纳入主方法。只有在保留几何精度的同时，冲突/置换文本能稳定改变宏观事件对应的轨迹，才有理由采用该策略。

## 未解决边界

视觉 mask 不能凭单一真实未来监督学习任意反事实 narration 对应的三维轨迹；它也会放大第一阶段 narration 错误向第二阶段传播的风险。正式采用前仍需在更多视频、文本置换和 hard-negative 条件上验证。
